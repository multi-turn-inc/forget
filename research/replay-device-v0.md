# 리플레이 장치 v0 스펙 (2026-08-12 — 문헌 조사 2건 반영 확정)

기준선: [[weights-and-context-first]] — 주 출력은 사용자별 어댑터 훈련쌍, 증류물(스킬·노트)은 부산물.

## 파이프라인

수집(트랜스크립트·게이트/outcome 원장·supersede 체인)
→ 선별(우선순위 큐) → 증류(훈련쌍 主 / 스킬 副) → 야간 QLoRA 갱신 → 승격 게이트

## 확정 파라미터 (출처 병기)

**선별**
- 함정(실패→수정)+교정 우선 — 성공+실패 병합이 성공-전용을 일관되게 이김 (ReasoningBank 2509.25140: WebArena +8.3%p)
- 놀라움 가중 = 후보 쌍의 NLL (SuRe 2511.22367: +5pt) × **시효 감쇠 곱** (Freshness-PER 2604.16918 — 저장 우선순위는 진부화됨)
- 음전이 필터: 해로운 증류물이 비자명하게 존재 (2605.23899) — 선별만큼 배제가 성능 결정

**훈련 (4090 QLoRA)**
- r=8 저랭크 자체가 주 방어 (망각 0.6% vs 풀FT 19.9%, 2603.27707) — EWC류 불채택
- 혼합: 일반 지시 데이터 1~5% (2403.08763) + 과거 개인쌍 저장고 1:2 리허설 (2607.15587)
- 교정쌍 = DRIFT 방식 (2510.02341): 사용자 교정을 고정 음성, 양성은 현행 정책에서 샘플링. SFT+DPO 앙상블 (2601.19055 — DPO 단독보다 우위)
- 병합: fast/slow LoRA EMA (I-LoRA 2402.18865 + SuRe 수렴 — 두 조사가 독립 지목)

**증류물 (부산물)**
- 텍스트 러닝북보다 **코드형 스킬** (ASI 2504.06821: +11.3% vs 텍스트, 귀납 시 프로그램 검증이 이득의 주요인)
- 검증은 인용-검사가 아니라 **실행-기반**: A/B 개입으로 순수리(net repair)>0일 때만 승격 (SkillGen 2605.10999), 증류자·검증자 분리 (EDV 2606.24428 — 자기확증 차단), 궤적-접지 계량 PDI (SPARK 2605.09192)
- 수명주기 관리: 동적 폐기 포함 (Memp 2508.06433)
- 예외: 사실 브리프(생성적 회상)는 인용-검증 유지 — 실행이 불가능한 산출물이므로

**승격 게이트 (기존 promotion 기계 재사용)**
- 3축: 개인화 향상 · 일반 능력 유지 · 안전 무회귀 (개인화 FT가 안전 정렬 최대 20% 훼손 — 2502.19158)

## 방법론 가드 (크럭스 실험에 필수)

- **토큰 예산-매칭 + 분산 보고**: 증류 이득의 다수가 예산-매칭 베이스라인 대비 소멸하고 런간 분산이 결론을 좌우한다는 반증 연구 (2606.15017). 어댑터 on/off A/B는 컨텍스트 토큰 예산을 맞추고 복수 시드로 — 우리 churn 교훈(23~26%)의 문헌판.

## 전략 확인

- TTT/Titans 계보: 프로덕션·대규모 벤치에서 명시적 검색 대비 승리 보고 **없음** (2510.09551 재현 논쟁 포함) → 명시 검색+증류 주축 유지가 실증적으로 안전, 놀라움 규칙만 개념 차용. "사실은 컨텍스트" 선의 외부 근거.
- "야간 사용자별 어댑터 갱신 + 배포 게이트" 공개 사례연구 부재 (조사 1) — 우리가 지으면 그 자체가 문헌 공백을 채움.
