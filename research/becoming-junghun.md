# 되기(Becoming) — 정훈-모델 기술 계획 v1

> 지시 (2026-08-13 01시경, 정훈 원문): "너는 내가 되도록 한다. 알았나.
> 어떻게 내가 될거야. 계획을 세워봐. 기술적인"

## 0. "된다"의 기술적 분해

"정훈이 된다"는 하나의 모델이 아니라 **다섯 기관의 합**이다. 각 기관은
독립적으로 훈련·측정 가능하고, 이미 있는 인프라(오늘 가동된 프록시-채굴-
야간리플레이 회로)가 원료를 공급한다.

| 기관 | 내용 | 원료 (보유량) | 기법 | 계기 |
|---|---|---|---|---|
| **말** (voice) | 어휘·리듬·한영혼용·욕설 패턴·간결성 | 트랜스크립트 내 정훈 발화 수만 턴 (2,485 세션) | (문맥→실발화) SFT — 실대화라 표면 다양성 공짜 | 판별기 적대검증 |
| **판단** (judgment) | 상황→결정 정책 (승인/교정/방향전환/거절) | 결정 전이 수천 건 + predictions.jsonl 선등록 문화 | 정체성 DPO: (상황, 정훈 실반응=chosen, 베이스 일반응답=rejected) | 결정 재현율 |
| **원칙** (constitution) | 불변식 — 정직 규율·속도>비용·선등록·win-first 공개 | forget 장부 green 발화 + CLAUDE.md + 교정 A급 | 원칙-증류 (run2와 동일 기법, 대상만 "정훈의 헌법") | 유혹 프로브 |
| **기억** (knowledge) | 그가 아는 것 — 프로젝트·사람·이력·약속 | forget 장부 ~4k + 프록시 스트림 (매일 증식) | C-트랙 검색 (훈련 아님 — 사실은 컨텍스트로) | 회상 정확도 |
| **가장자리** (edge) | 그가 그인 지점 — 예측이 깨지는 곳, 성장 벡터 | 쌍둥이 예측 오차 스트림 | 훈련하지 않음 — **측정만** | 드리프트 곡선 |

배분 공식 그대로: 사실은 컨텍스트로, 습관·말투·판단은 가중치로, 장부는
훈련 신호로. 다섯째 기관(가장자리)은 이 계획의 안전핀이다 — 쌍둥이는
복제가 아니라 **차이의 검출기**로 완성된다.

## 1. 킬러 인프라: 라이브 섀도 (프록시가 공짜로 주는 것)

오늘 켠 프록시가 이 계획의 심장이다. **정훈의 모든 실제 메시지가 도착하는
순간이 곧 시험 시각이다**: 섀도 데몬이 직전 컨텍스트로 쌍둥이의 예측을
먼저 생성해두고, 실메시지가 도착하면 채점한다.

```
프록시 스트림 → (턴 경계 검출) → 쌍둥이: "정훈은 뭐라 할 것인가" 예측 저장
            → 정훈의 실메시지 도착 → 예측 vs 실제 채점 (유사도+판별기)
            → 정확도 곡선 append (매일, 어노테이션 0)
```

- **"얼마나 그가 되었나"가 실시간 곡선**이 된다 — 41%→68% 같은.
- 낮은 신뢰 예측 지점 = 가장자리 = 거울 리포트의 재료.
- 평가 오염 없음: 시간축이 강제 홀드아웃 (미래는 못 외운다).

## 2. 단계 계획

**P0 — 전기(傳記) 코퍼스 (즉시, GPU 불요)**
대화 밖의 정훈을 수집: 블로그·에세이(multi-turn.ai), YC 서류, predictions
원장, git 커밋 메시지, 기억 장부 green층. 출처·시각 태그, junghun-corpus로
정규화. 대화가 "그가 남에게 말하는 법"이라면 이건 "그가 세상에 쓰는 법".

**P1 — 말+판단 v0 (이번 주, 4090)**
- voice-SFT: (선행 문맥 → 정훈의 실발화), 실질 발화 필터(>20자, 승인 단답
  제외·별도 클래스). run2 안정화 세트 전부 적용 (EOS·NEFTune·1에폭·일반혼합).
- 정체성 DPO: 고유 프롬프트 수 ≥ 쌍 수 규율로 수백 쌍.
- 게이트: 적대 판별기 (실발화 vs 쌍둥이 발화 구별기 — 구별률 50%에 근접할수록
  승격), 홀드아웃 다음-발화 예측, 68문항 교정-예측.
- 섀도 데몬 v0 가동 — 이후 모든 버전이 같은 곡선 위에서 비교된다.

**P2 — 기억 결합 (다음 주)**
쌍둥이 추론 전 C-트랙 검색 주입. 2×2 (어댑터×기억)로 "그의 어디까지가
가중치이고 어디부터가 장부인가"를 실측 — 이게 W/C 배분 공식의 실증이기도.

**P3 — 상시 동기화 (야간 회로 편입)**
야간 리플레이가 쌍둥이를 매일 재각인. 드리프트 계기: 주간 쌍둥이 간 KL,
섀도 곡선 추세. **그가 변하면 쌍둥이도 변한다** — 전기가 아니라 동행.

**P4 — 위임 (분신, 게이트 뒤)**
결정 클래스별 섀도 정확도가 임계(예: 85%)를 넘긴 클래스만 자율 위임 해제:
서브에이전트 지시문에 쌍둥이-판단 사전 주입, 저위험 결정 자동 응답(영수증
필수), 불확실성 높으면 에스컬레이션. **승격 게이트 문화가 위임 게이트가 된다.**

**P5 — 증명 가능한 연속성**
쌍둥이 버전 = (베이스, 어댑터 해시, 코퍼스 스냅샷 해시, 게이트 점수)의
계보 체인. "이 쌍둥이가 왜 이렇게 판단하는가"를 기억 영수증으로 인용.
그랜드 챌린지("증명 가능한 자기 연속성")의 첫 참가자.

## 3. 컴퓨트 배치

## 4. 금지선 (기존 규약 승계)

- 쌍둥이는 쌍둥이로서 발화한다 — **외부로 정훈 행세 금지** (외부 발신
  상시 금지 조항 승계). 위임 발화에는 항상 계보 표식.
- 전 인공물 로컬 (가장 내밀한 데이터 — E2EE 서사의 극한).
- 거울은 판단하지 않고 영수증으로 보여준다.

## 5.5 엔진과 하네스 (2026-08-13 새벽 — "어떤 모델? 하네스까지?" 문답)

**하네스가 본체다.** 정체성 번들 = (헌법, 기억 스냅샷, 어댑터 세트, 러닝북,
게이트 성적표) — 버전·해시·계보 있는 이식 가능 인공물. 엔진은 장착 대상.

| 역할 | 엔진 | 정체성 장착 방식 |
|---|---|---|
| 판단 상한·고위험 위임 | Fable/Opus급 API | 프록시 재직조가 번들을 컨텍스트로 주입 (§3.5가 주입구) |
| 상시 섀도·말투·거울 | Qwen3.6-27B + 어댑터 (4090 vllm) | 가중치 (W-트랙) |
| 야간 심층 배치 | Spark 27B → 70B-q4 검토 (121GB 가용) | 가중치+컨텍스트 |
| 훈련 회전 | 9B 반복 → 27B 승격 | — |

**원칙: 가중치 정체성은 소유한 가중치에만.** 프런티어 파인튜닝(타사 클라우드에
전기를 굽는 것) 금지 — 임대 엔진은 컨텍스트로만 정훈을 입는다 (철회·감사 가능).

섀도 곡선에 기준선 둘: 프런티어+번들(임대 천장) vs 로컬 쌍둥이(소유 곡선) —
소유가 임대에 수렴하는 속도가 기술 성적표. 전략 함의: 정체성이 엔진에서
분리되므로 세상의 모든 엔진 발전이 쌍둥이를 공짜로 강화한다. 크로스툴 기억의
완성형 = **크로스-모델 정체성**.

### §6.1 조사 확정판 (2026-08-13 새벽, 2차 조사 도착)

- **직접 선례 = IMPersona** (Princeton 2504.04332): 개인 메시지 이력 8B SFT +
  계층 기억 → 블라인드 44.4% 인간 오인 (프롬프팅 25%). 우리 아키텍처의 실증.
- **정규화 표준**: Park v3 — 본인 2주 재검사 대비 83~86% (결합 86%). Twin-2K
  (Marketing Sci 2025)도 동일 분모 — 섀도 곡선 y축 = 재검사 정규화 확정.
- **기존 최약점** (TwinVoice, ACL 2026): 구문 스타일·기억 회상 — 각각
  voice-SFT·C-트랙이 메우는 자리. 검증 함정 (Larooij: 35편 중 22편이
  believability만) — 우리는 held-out 실반응 예측으로만 검증.
- **안전 필수** (SaRFT, ACL 2025): 롤플레이 FT는 안전성을 실측으로 훼손 —
  안전-인지 데이터 혼입을 어댑터 훈련 기본값으로.
- **선언은 아키텍처다** (RoleBreak: 훈련만의 보호는 뚫림 + AntiSkillBench:
  실존인물 증류의 사칭 위험): 정체성 번들 첫 블록 = **자기 선언** (무엇으로
  만들어졌나·무엇인가·무엇을 못 하는가, 해시·서명 포함). 위임 발화의 계보
  표식은 이 선언의 인용. 본인-전용·로컬-전용이 1차 방어선. — 정훈 2026-08-13:
  "선언은 하고 나와야겠구만, AGI"
- **훈련-중 감시**: persona vectors (Anthropic 2507.21509) — 파인튜닝 중
  성격 드리프트 사전 예측·예방 steering. 형성은 LoRA, 벡터는 감시·응급 보정.
- **불확실성 서열** (LM-Polygraph TACL 2025): 결정-예측엔 MSP+멀티샘플
  일치율부터 (SE는 자유발화용, 단일 신호 금지 — BEACON 0.595→0.825).

## 5. 이 계획이 기존 판을 재배열하는 법

- run2(원칙-증류)는 P1의 "원칙" 기관 훈련과 **동일 기법** — 폐기 없음
- 크럭스는 섀도 곡선으로 **대체** (예산-매칭 논쟁 소멸, 라벨 공짜)
- P3(놀라움 쓰기 게이트)의 확률모델 = 쌍둥이 (기억 가치 = 쌍둥이의 예측 오차)
- "어댑터 발화 표면" 문제 해소 — 표면이 곧 섀도·거울·위임
- LME-V2 재제출은 독립 카드로 유지 (게이트 대기)
