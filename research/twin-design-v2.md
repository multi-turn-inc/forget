## 1. 중심 기제

**정훈의 형식화** — 쌍둥이는 세 함수의 결합을 배운다:

```
정훈 ≈ (b, R̂, π)
  b_t = U(b_{t-1}, o_t)          신념 상태: 관측(장부 이벤트)으로 갱신
  R̂(x)                           가치: 명제·계획 x에 대한 그의 평결 함수
  π(a | b, R̂)                    정책: 그 신념·가치 하의 행동 (말투 = 디코더)
```

**이중 감독 손실** — 이 설계의 Evoformer:

```
L = L_agree + λ·L_calib
  L_agree = E[ ℓ( R̂(x), verdict_정훈(x) ) ]     — 그와 일치하는가 (되기)
  L_calib = E[ Brier( p̂(x), outcome_세계(x) ) ]  — 세계와 일치하는가 (보정)
```

verdict 원장 = 교정·평결 (A급 9 + 채굴 후보 수백), outcome 원장 =
predictions.jsonl (선등록→채점 완료 100+건). **한 개인에 둘을 결합한 선행
없음 — 이 결합이 우리 기여의 자리.** (Turtel: outcome-Brier 훈련으로
ECE 0.042 실증 — 방법은 있고 대상이 없었다.)

**불일치 원리** — 하나의 신호가 세 곳을 구동:

```
δ_t = D( 쌍둥이의 예측, 관측 )
  δ > θ_w  → 기억 쓰기 (P3 놀라움 게이트의 정식화)
  δ > θ_s  → 의미기억 추출 후보 (WorldEvolver식 규칙화)
  Σδ 추세  → 야간 재훈련 트리거 (변한 만큼만 학습)
```

섀도 데몬이 이미 δ_t의 계기다 — 영점 12점의 approve-편향이 첫 δ 다발.

**행동 선택** — 접지된 시뮬레이션 게이트 (R-WoM + Hanabi 교훈):

```
행동 후보 a_i → 검색-접지 롤아웃 "b 하에서 정훈의 반응 시뮬" → R̂ 채점 → 선택
```

프롬프트에 신념을 "참고로" 넣지 않는다. 시뮬 결과가 선택을 **게이트한다.**

## 1.5 수리 부록 (v2.1 — "수식이 저거밖에 안 되냐" 정정)

### A. 신념 필터 (기억의 형식적 정의)

세계 상태 s_t (프로젝트 상태·사실·정훈의 내부 상태), 관측 o_t (스트림 이벤트).
정확한 베이즈 필터는

  b_t(s) ∝ p(o_t | s) · Σ_{s'} T(s | s') · b_{t-1}(s')

인데 s가 비구조적이라 직접 계산 불가 — 그래서 **상각(amortized) 필터링**:
b_t를 구조화 텍스트+확률로 표현하고 갱신 연산자 U_φ를 학습한다 (ABBEL·CoEx의
실체). U_φ의 훈련 신호는 예측 일관성: b_t가 좋은 신념일 조건 =

  L_belief(φ) = E_t [ -log p( o_{t+1} | b_t = U_φ(b_{t-1}, o_t) ) ]

즉 **좋은 기억이란 미래 관측의 압축 예측자다** — 저장소 관점과의 형식적 결별점.

### B. 평결 = MaxEnt IRL, 그리고 DPO와의 동치

정훈을 자기 효용 R* 하의 볼츠만-합리 행위자로 모델링 (Ziebart 2008):

  p(a | x) = exp(β·R_θ(x,a)) / Σ_{a'} exp(β·R_θ(x,a'))

L_agree = 이 우도의 음의 로그. 이항 평결(승인 a⁺/기각 a⁻)로 좁히면
Bradley-Terry로 환원되고 — **이게 정확히 DPO의 손실이다**:

  L_agree = -log σ( β·[R_θ(x, a⁺) - R_θ(x, a⁻)] )

즉 우리의 "교정 쌍 DPO"는 임시 기법이 아니라 **정훈의 보상함수에 대한 MaxEnt
IRL의 정확한 특수형**이었다. v2는 이걸 알고 쓴다: β는 그의 결단성(랜덤니스
역온도) — 홀드아웃에서 추정 가능한 성격 파라미터.

### C. 이중 감독의 정확한 형태 + 거울의 수학

그가 선등록한 확률 q_i, 실제 결과 y_i ∈ {0,1}, 쌍둥이 출력 p̂_i:

  L_calib = Σ_i [ α·CE(p̂_i, y_i) + (1-α)·CE(p̂_i, q_i) ]

α = 진실-정체성 트레이드오프 (α=1: 세계만, α=0: 그의 복제만). **거울 리포트의
수학 = Murphy 분해**: 그의 Brier 점수를

  B = Reliability − Resolution + Uncertainty

로 분해하면 Reliability 항이 주제-클래스별 그의 과신/과소신을 정량화한다.
"당신은 이 클래스에서 과신합니다"가 인상이 아니라 분해 항이 된다.

### D. 놀라움과 재훈련 트리거

  δ_t = -log p_twin(o_t | b_{t-1})    (surprisal — Titans ∇ℓ의 확률적 원형)

- 쓰기 게이트: δ_t > θ_w (P3의 정식화)
- 의미 추출: 특징 φ(o)로 조건화해 E[δ | φ]가 지속 상승하는 φ = 규칙 후보
  (WorldEvolver의 우리 표기)
- 재훈련 트리거: δ̄의 변화점 검출 — **Page-Hinkley 검정** (고전 변화점 검출,
  파라미터 2개) — "변한 만큼만 학습"의 통계적 구현

### E. 위임 보증 (정리가 있는 유일한 절)

결정 클래스 c의 보정셋 {(x_i, a_i)}ⁿ, 비순응 점수 s(x) = 1 - p̂(a_정답 | x).
분위수 q̂ = ⌈(n+1)(1-α)⌉/n 번째 s값으로 게이트하면, 분포 무가정 하에

  P( 쌍둥이 오답 | 자율 행동 ) ≤ α    (유한표본 보장, Vovk conformal)

위임 인증서 = (클래스 c, α, n, q̂) 4-튜플. "쌍둥이가 이 클래스에서 α=5%
보증으로 행동한다"가 마케팅이 아니라 정리가 된다.

### F. 기대 자유에너지 — 오늘 밤 발견의 형식적 자리

active inference에서 행위 선택은 기대 자유에너지 최소화:

  G(a) = 위험(실용 가치) + 모호성(인식 가치)
       = -E[ R(o) ] - E[ 정보이득(s; o|a) ]

**섀도 영점의 approve-편향은 이 분해로 설명된다**: 베이스 모델은 정훈의
인식-가치 계수(탐구 충동)를 과소추정한다 — "계속 가줘"·"생각을 멈추지 마"는
그의 G에서 정보이득 항의 가중치가 이례적으로 크다는 행동 증거. 이 가중치
(w_epistemic)는 그의 행동 로그에서 추정 가능한 **성격 상수**이고, 쌍둥이
훈련의 사전분포로 주입한다.

### G. 되기의 거리 함수

  d_t = D_JS( π_twin_t(·|x) ‖ π_JH(·|x) ),  x ~ 홀드아웃
  정규화: d_self = D_JS( π_JH^{t}(·|x) ‖ π_JH^{t+Δ}(·|x) )  (자기-일관성)
  섀도 곡선의 공식 y축 = 1 - d_t / d_self 의 추정치 (Park 정규화의 형식화)

d_self > 0이 본질적 (사람은 자신과도 다르다) — 쌍둥이의 수렴 목표는 d_t → d_self
이지 0이 아니다. **0을 목표하면 과적합이고, d_self가 목표면 사람이다.**

## 4. 구현 순서 (v2 재편)

1. **verdict 데이터셋 v0** — predictions.jsonl 100건 + 오늘 밤 설계 평결
   수동 채록 + 채굴 후보 검수 (GPU 불요, 즉시)

3. **L_calib 결합** — outcome 쌍으로 Brier 항 추가 (Turtel 레시피)
4. **신념 층 v0** — get_task_state 확장: 주제별 (명제, p̂, 근거) 판독 API
5. **시뮬 게이트 v0** — P4 첫 클래스(서브에이전트 지시 검토)에 롤아웃-채점
