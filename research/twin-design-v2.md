# 쌍둥이 설계서 v2 — 신념·평결·불일치 (2026-08-13)

> v1("배관은 완결, 아이디어 부재" — 정훈 판정 정확했음)의 개정.
> 근거 = 조사 2건의 수렴 (연구/replay 참조: IRL·ToM 조사 + 월드모델×기억 조사).
> v1의 배관(프록시·채굴·게이트·섀도)은 전량 재사용 — **과녁만 바꾼다.**

| v1 (기각) | v2 (채택) | 근거 |
|---|---|---|
| 발화 모방 (문맥→그의 말) | **판단 예측** (명제→그의 평결) + 말은 디코더 | 출력이 아니라 생성기; 개인 예측 상관 ~0.2의 냉수를 뚫은 사례는 전부 판단-이력 기반 (SPF) |

| 회상 = 검색 주입 | **신념이 행동을 게이트** | Hanabi 실측: 프롬프트 장식 무효, 행동 게이트 20%→100% |

| 모방 손실 단독 | **이중 감독** | 미점유 결합 (조사 ① 종합) |

## 1. 중심 기제

**정훈의 형식화** — 쌍둥이는 세 함수의 결합을 배운다:

```
정훈 ≈ (b, R̂, π)
  b_t = U(b_{t-1}, o_t)          신념 상태: 관측(장부 이벤트)으로 갱신
  R̂(x)                           가치: 명제·계획 x에 대한 그의 평결 함수
  π(a | b, R̂)                    정책: 그 신념·가치 하의 행동 (말투 = 디코더)
```

**이중 감독 손실** — 이 설계의 Evoformer:

```
L = L_agree + λ·L_calib
  L_agree = E[ ℓ( R̂(x), verdict_정훈(x) ) ]     — 그와 일치하는가 (되기)
  L_calib = E[ Brier( p̂(x), outcome_세계(x) ) ]  — 세계와 일치하는가 (보정)
```

verdict 원장 = 교정·평결 (A급 9 + 채굴 후보 수백), outcome 원장 =
predictions.jsonl (선등록→채점 완료 100+건). **한 개인에 둘을 결합한 선행
없음 — 이 결합이 우리 기여의 자리.** (Turtel: outcome-Brier 훈련으로
ECE 0.042 실증 — 방법은 있고 대상이 없었다.)

**불일치 원리** — 하나의 신호가 세 곳을 구동:

```
δ_t = D( 쌍둥이의 예측, 관측 )
  δ > θ_w  → 기억 쓰기 (P3 놀라움 게이트의 정식화)
  δ > θ_s  → 의미기억 추출 후보 (WorldEvolver식 규칙화)
  Σδ 추세  → 야간 재훈련 트리거 (변한 만큼만 학습)
```

섀도 데몬이 이미 δ_t의 계기다 — 영점 12점의 approve-편향이 첫 δ 다발.

**행동 선택** — 접지된 시뮬레이션 게이트 (R-WoM + Hanabi 교훈):

```
행동 후보 a_i → 검색-접지 롤아웃 "b 하에서 정훈의 반응 시뮬" → R̂ 채점 → 선택
```

프롬프트에 신념을 "참고로" 넣지 않는다. 시뮬 결과가 선택을 **게이트한다.**

## 2. v1 배관의 재사용 맵 (버리는 것 없음)

| v1 부품 | v2 역할 |
|---|---|
| 프록시·스트림·재구성 | 관측 o_t 공급 (불변) |
| 채굴기 (교정·행동사례) | **verdict 원장** 채굴기로 재명명 |
| predictions.jsonl 문화 | **outcome 원장** — L_calib의 데이터 (이미 100+ 채점됨) |
| forget 장부 | 관측 로그 (불변 원료) — 위에 신념 층 신설 |
| get_task_state/캡슐 | 신념 층의 원시형 → b_t API로 승격 |
| 섀도 데몬 | δ_t 계기 (이미 가동) + 보정 곡선 추가 |
| voice-SFT (훈련 중) | 디코더 훈련으로 강등 (폐기 아님 — 말투는 여전히 필요) |
| 원칙-증류 119 | R̂의 사전분포 (그의 헌법 = 가치의 명시 부분) |
| 게이트 프로브·야간 회로 | 불변 |

## 3. 데이터 재정의

- **verdict 쌍**: (명제/계획/보고, 정훈의 평결{승인·기각·정정+사유}) —
  소스: 교정 채굴 + 이 대화들의 설계 문답 (오늘 밤만 해도 "35B 기각·27B 채택",
  "프라이버시 제약 오적용", "v1 구조 기각" 등 평결 다수)
- **outcome 쌍**: (선등록 예측, 실제 결과) — predictions.jsonl 그대로
- **신념 层 스키마 v0**: 주제별 (명제, p̂, 근거 이벤트 링크, 갱신 이력) —
  supersede 체인이 이미 갱신 이력의 반쪽
- 발화 쌍 1,525는 디코더용으로 유지

## 4. 구현 순서 (v2 재편)

1. **verdict 데이터셋 v0** — predictions.jsonl 100건 + 오늘 밤 설계 평결
   수동 채록 + 채굴 후보 검수 (GPU 불요, 즉시)
2. **R̂ v0** — 평결 예측 과제로 어댑터 훈련 (L_agree만; 시간 분할)
   → 섀도에 "평결 예측" 트랙 추가
3. **L_calib 결합** — outcome 쌍으로 Brier 항 추가 (Turtel 레시피)
4. **신념 층 v0** — get_task_state 확장: 주제별 (명제, p̂, 근거) 판독 API
5. **시뮬 게이트 v0** — P4 첫 클래스(서브에이전트 지시 검토)에 롤아웃-채점
   적용: 지시문을 쌍둥이가 "정훈 반응 시뮬"로 사전 채점
6. 생성적 리플레이(SSR식)는 야간 회로 정착 후 — 개인화 어댑터 적용의
   첫 실증 자리 (문헌 공백 ②)

## 5. 계측 (v1 계기 + 신규 2)

- 섀도 곡선 (유지: 방향·유사도) + **평결 정확도 트랙** (신규)
- **보정 곡선**: 쌍둥이 p̂의 ECE/Brier — "세계에 대해 정훈만큼 잘 아는가"
- 거울 확장: 쌍둥이가 정훈보다 보정이 좋은 클래스 = **정훈의 miscalibration
  거울** (조사 ①의 미점유 지대)
