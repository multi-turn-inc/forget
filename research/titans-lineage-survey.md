# 테스트-타임 기억 계보 조사 (조사 에이전트, 2026-08-11)

발주: 정훈 "후속 논문들도 찾아봐야 할듯. 파라메트릭이지만 인사이트는 얻을 게 있을 것 — 동적 처리잖아."
원문 전체는 세션 기록. 이 파일은 정본 요약.

## 핵심 관찰 (역설적 수렴)

계보의 진화 방향 — 매 토큰 → 창/사건 단위 쓰기(ATLAS·LaCT) → 다중 신선도
계층(HOPE CMS·TNT) → 버전 스냅숏(Memory Caching) → 오프라인 수면 통합(Sleep)
— 은 전부 **명시적 저장소가 공짜로 얻는 성질**이다. 파라메트릭 진영은 이를
비싸게 재발명 중이고, **감사 가능성만은 구조적으로 재발명할 수 없다.**

## 공백 진단 (전 논문 확인 — 포지셔닝의 문헌적 증거)

출처 추적 부재 · 표적 정정 불가(망각=통계 감쇠뿐) · 커버리지/신선도 보고 부재 ·
신뢰 라벨 개념 부재. 단 2026년부터 공백이 명명되기 시작(Always-On 서베이
2606.30306 "축적·회수 편중, 통치·복구·폐기 공백"; Beyond Perplexity 2607.00368은
파라메트릭 기억 주장의 검증 기준선으로 **명시적 기억**을 채택) — 창이 열려
있으나 닫히기 시작하는 신호. 포지셔닝 인용 1순위: 2607.00368.

## 즉시 훔칠 것 (P-체계 매핑)

| 출처 | 규칙 | 우리 자리 |
|---|---|---|
| EM-LLM (2407.09450) | 베이지안 놀라움 사건 경계 + **시간 인접 회상**(회상된 사건의 이웃도 함께) | 캡처 분절 + 회상 확장 — 즉시 이식 가능 |
| Gated DeltaNet (2412.06464) | 삭제(게이트)와 표적 덮어쓰기(델타)는 **다른 연산** | supersede vs decay 분리의 독립 근거 |
| Lattice (2504.05646) | 현재 상태와 **직교인 성분만 기록** | P3 중복-제거 쓰기 규칙의 수학형 |
| Miras (2504.13173) | 정책 = 쓰기손실 × 보존게이트 × 스케줄. Huber(이상치 놀라움 완충)·KL(정정 시 점진 이행) | P2·P3 설계 카탈로그 |
| HOPE CMS (2512.24695) | 갱신 주파수 스펙트럼 기억 계층 | 세션→일간→주간→프로필 계층의 청사진 |
| Sleep (2606.03979) | 온라인 쓰기와 오프라인 통합(증류+재연)의 분리 | 야간 통합 잡의 이론적 등가물 |
| Test-time regression (2501.12352) | 기억=가중 회귀, 회상=회귀해 평가. γ = 가중치 설계 | 회상 랭킹(최근성×중요도×신뢰)의 이론 언어 |
| Beyond Perplexity (2607.00368) | 행동 평가 사다리 + 명시적-기억 대조군 | 제품 회상 벤치마크 설계도 |

## 정독 순서

1. Miras (2504.13173) — 기억 정책의 설계 공간 지도
2. Nested Learning (2512.24695) — 신선도 스펙트럼 + 자기수정 메타 루프
3. Test-time regression (2501.12352) — 계보 전체를 한 언어로 읽는 렌즈
