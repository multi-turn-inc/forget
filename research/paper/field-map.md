# AI 메모리 필드 맵 — 2025–2026 (2026-07-17 조사)

방법: deep-research 워크플로 (103 에이전트, 5각도 검색 → 15소스 정독 → 주장별 3표
적대검증). 세션 한도로 마지막 검증 배치(MemForest/CALMem 4건)와 종합이 미완 — 해당
주장은 fetch 단계 원문 인용 기반이며 MemForest 헤드라인 수치(79.8)는 arXiv 초록에서
직접 재확인함. 상세 원자료: 워크플로 journal (wf_2821251d-c01).

## 지형도 (축별 핵심 플레이어)

**축1 — 쓰기 시점 구축/압축**: MemGPT/Letta(2023) → Generative Agents → Mastra OM(2026,
관찰/리플렉션) → **LightMem**(보조 소형모델 추출) → **MemForest**(2026-05, VLDB 제출:
시간순 트리, leaf=원문·내부노드=구간요약) → **EverMemOS, MemoryOS, MemPalace**(2025–26
스테이트풀 시스템 세대). 필드 대세: 구축은 이미 "당연히 하는 것", 경쟁은 효율(처리량)과
시간 충실도로 이동.

**축2 — 멀티 그래뉼러리티/하이브리드 검색**: RAPTOR(2024, 일반 도메인) →
**HiGMem**(2026: 요약층+원문층 동시 검색, 층별 고정 top-k(k_turn=10, k_event=10) —
**층화 듀얼의 직접 선행**, 단 LoCoMo10만 평가·최종 선별은 LLM 필터링) →
MemForest(요약→원문 순차 트리 탐색) → CALMem(원문 청크만, 요약층 명시적 거부).

**축3 — 시간 추론/supersession**: Zep/Graphiti → **MemForest가 현 선두**: wrong-time
retrieval 문제 정식화(Boston→Davis→Miami에서 중간 상태 복원), 비파괴 상태 보존,
temporal pass@1 79.7%. TiMem(시간-계층 통합). ⚠️ 우리 supersede 명제와 정면 겹침.

**축4 — 망각/수명주기**: 서베이(2605.06716, 3-0 검증)가 "무제한 축적은 오류 전파로
성능 저하, 전략적 삭제 정책 필요"를 명시 — **문제 인식은 합의, 해법은 공백.**
MemForest가 targeted deletion/merge 지원. 학습된 가치판별 게이트는 미점령.

**축5 — 벤치마크**: LongMemEval/LOCOMO 양강 유지. **HaluMem**(2025): 메모리 시스템의
환각 평가 — 인접하나 오염-강건성과는 다름. LoCoMo adversarial 카테고리가 유일한
근접물인데 **모든 시스템의 최약점**(MemForest 29.6–35.9 vs 최고 44.8) — 오염/노이즈
강건성이 필드의 무른 배라는 증거. **실사용 오염 스토어 기반 벤치마크는 부재.**

**축6 — 온디바이스/증류**: **MemLoRA**(2512.04763, 2025-12, 3-0 검증): 메모리 3연산
(추출·갱신·생성)을 연산별 LoRA 어댑터로 SLM에 증류, 프라이버시 동기 명시, LoCoMo에서
10×大 모델 능가. **DuoMem**(2026-06): 교사 생성 메모리를 기기에 배포(context-space) —
관찰자 학습과는 다름. MemForest: 증류 없이 off-the-shelf Qwen3-4B로 70.4%, 30B로 79.8%.

| (b) 오염 스토어 벤치마크? | **부분 점유, 핵심은 공백 — Path A 생존** | HaluMem=환각(다른 문제), LoCoMo-adv=소규모 인접물. 실오염 기반 회수 열화 측정은 없음 |
| (c) 층화 듀얼 선행? | **직접 선행 존재 — novelty 주장 불가** | HiGMem 층별 top-k 동시 검색. 단 LoCoMo10 한정, 층화 "예산" 분석과 원풀-경쟁 발견은 우리 것 |

## 우리 숫자의 재위치 (뼈아픈 것)

MemForest: LongMemEval-S **79.8%** (Qwen3-30B 로컬 백본), 구축 처리량 6×.
우리: 81.8%(gpt-4o observer+reader), O2 로컬 78.6%(n=42).
→ "우리 81.8"은 더 이상 인상적인 절대치가 아니며, **"로컬 구축" 축도 MemForest가 선점.**
게임 3(로컬-온리)의 신규성 주장은 접어야 함. 남는 것: 동일 하니스 공정 비교,
원풀-경쟁 분석, 유의성 검정, 정직 방법론 — 테크리포트감이지 톱티어 주장이 아님.

## 결론 — 논문 전략 수정

1. **테크리포트(arXiv)**: 유지하되 재포지셔닝 — "독립 재현 + 층화 예산 ablation +
   경쟁 분석" (MemForest·HiGMem·MemLoRA 인용, novelty 주장 제거). 스타트업 신뢰용.
2. **Path B(증류) 폐기.** MemLoRA + MemForest로 양쪽에서 선점. 로컬 스윕은 테크리포트
   섹션으로 강등.
3. **Path A(dirty-store)가 유일한 톱티어 후보로 승격** — 차별화 조건:
   - 유일 자산: **8개월 실사용 스토어의 실제 오염 분류(88%, N=106)** — 전 필드가 합성/클린만 씀
   - HaluMem과 구획: 저쪽은 "메모리 연산이 만드는 환각", 우리는 "오염된 스토어가
     회수·응답에 입히는 열화 + 게이트/망각 정책이라는 처치(treatment)"
   - LoCoMo-adv가 전 시스템 최약점(30–45%)이라는 사실이 시장성 근거
   - 시스템 횡단 평가(Mem0, Zep, Letta, MemForest(공개시), forget) = 벤치마크 논문의 격
   - E1 v0의 null이 설계 가이드: 합성 키토큰·소규모에선 안 나타남 → 실코퍼스·스케일 필수

## 부록: 시도 α 킬 스위치 결과 (2026-07-17, research/alpha/pilot.summary.json)

**α(LOO 반사실 라벨링) 기각.** 정답 11건 중 단일 기억 제거로 답이 뒤집힌 것은 2건뿐
(S1=0.18, 기준 0.5). 표적 플립율 1.5%, 대조 0%.

**기각의 원인이 그 자체로 발견**: k=102 검색 컨텍스트는 **대량 중복**이다 — 증거가
관찰층과 원문층 양쪽에, 원문 내에서도 여러 턴에 존재해 어떤 단일 삭제에도 답이 생존
(86%). 단일 기억의 한계 유틸리티는 라벨이 되지 못한다.

**β로의 이월**: 이 중복성이 E1 v0의 정크 내성 null을 설명한다 — 오염의 해악은 "정크가
증거의 마지막 사본까지 top-k에서 밀어낼 때" 발생한다는 **정량 모델**(오염 압력 vs 증거
중복도)이 β 벤치마크의 이론 프레임이 된다. β 단독 진행 확정.

## 부록3: 학습된 consolidation 계보 — 표적 조사 (2026-07-18, 원문 확인)

| 논문 | 학습 대상 | 보상 | 선점 범위 |
|---|---|---|---|
| MEM1 (2506.15841, ICLR'26) | 태스크 내 내부 상태 통합 (RL) | 태스크 성공+효율 | 단일 궤적 컨텍스트 관리 — 영속 스토어 아님 |
| Memory-R1 (2508.19828) | **쓰기: ADD/UPDATE/DELETE/NOOP (PPO/GRPO) + 읽기: 검색 후 필터링** | 다운스트림 QA EM (LoCoMo 152쌍) | **"미래 회수 성공을 보상으로 한 메모리 연산 학습" 선점** |
| CompactionRL (2607.05378) | 궤적 내 압축+실행 공동 학습 | SWE-bench류 태스크 성공 | 컨텍스트 압축 — 세션 간 스토어 아님 |

**Memory-R1의 확인된 한계 (= 우리 슬롯):**
1. **사실만 저장, 원문 파괴** — UPDATE는 직전 버전(old_memory)만 유지, 깊은 계보·영수증 없음
2. **좌표 부재** — 타임스탬프+화자뿐, 세션/프로젝트/과업 좌표 없음 (우리 맥락 소거 발견과 정확히 동형)
3. **턴 단위 처리** — 세션 수준 consolidation 아님 (24턴 창의 단일 사실 연산)
4. **클린 스토어만 평가** — 오염/충돌 상태 실험 전무

**3막 슬롯 확정 (좁혀진 형태):**
"**좌표 보존·영수증 유지·오염 강건**의 세션 수준 consolidation을 미래 구성 성공으로
학습" — 세 수식어가 각각 우리 실측 발견(맥락소거 0/2899, 듀얼 +6pp, dirty-store)에
근거. Memory-R1은 반박 대상이 아니라 직접 선행으로 인용하고 그 위에 쌓는다.
읽기 쪽 학습은 Memory-R1이 이미 함 — 우리 novelty는 쓰기 쪽에 집중.
β와의 관계: β가 질병의 측정이라면 3막은 학습된 치료 — β 하니스가 3막의 훈련 환경.
훈련 경로 현실화: RL 이전에 rejection sampling→SFT/DPO (4090 단일 카드 제약).
미검증 잔여: EMBER·HiMPO 상세 (2차 위협, MEM1 계보로 추정).
