# 3막 검증 계획 — 전향적 색인 (Prospective Indexing) 선등록

Status: v1.0, 2026-07-18. 판정 기준은 결과 확인 후 수정 금지.
가설: **쓰기 시점에 "미래의 어떤 질문이 이 흔적을 필요로 할까"를 예측해 단서(cue)로
심으면, 회수가 개선된다** — Memory OS 아키텍처의 프리페처 성능 검증과 동일물.
선행 인정: doc2query(IR)의 프리미티브 이식. novelty는 에이전트 설정(쓰는 자=묻는 자,
자기 질의 스트림으로 자가지도)과 세션 맥락 — 원시 기법 자체 아님.

## 누출·교란 통제 (전 단계 공통)

- **누출 금지**: 단서 생성기는 세션 내용만 본다. 벤치마크 질문·정답에 절대 비접근.
- **위약군(placebo)**: 단서를 엉뚱한 세션에 붙인 군(셔플) — "텍스트가 늘어서 매칭이
  느는" 아티팩트 통제. 처치군은 위약군도 이겨야 함.
- **예산 공정성**: top-k 슬롯 고정(42) — 후보 엔트리 수는 늘어도 회수 예산은 동일.
- **dev/held-out 분리 유지**: 튜닝은 dev(seed 42), 확정은 full-500.

## 단계 사다리 (각 단계가 다음의 킬 스위치)

### Stage 0 — 회수 전용 킬 스위치 (~$3, 반나절)
- dev-42 인스턴스. 세션당 예상 질문 3개 생성(gpt-4o-mini, 캐시).
- 3군 비교: baseline(원문 턴만) / treatment(턴+단서) / placebo(셔플 단서).
- 지표: **evidence-session coverage@42** (정답 근거 세션이 top-42 매핑에 포함된 비율,
  LongMemEval answer_session_ids가 ground truth — reader 호출 0, 임베딩은 로컬 fastembed).
- **판정: treatment ≥ baseline +5pp AND treatment > placebo +3pp. 미달 시 3막 즉사** —
  zero-shot 단서가 안 되면 학습된 단서도 안 됨(더 싼 반증 우선).

### Stage 1 — full-500 회수 + 이론 검정 (~$15, 1일)
- 단서 생성 full-500(~25k 세션, mini). 회수 지표 전량 + **r-층화 분석**:
  효과가 저중복(low-r) 질의에 집중되면 중복성 이론과 정합(β 프레임과 연결).
- 판정: 전체 +5pp AND low-r 사분위 효과 > high-r 사분위 효과.

### Stage 2 — 종단 QA 인과 확인 (~$80, 2일)
- 잠근 config(듀얼 42+42)에 단서 색인만 추가 → full-500 QA vs 80.8% baseline.
- 판정: **McNemar p<0.05** (n=42 노이즈 ±13pp 교훈 — 쌍대 검정만 신뢰).

### Stage 3 — 논문 본체 (통과 시)
- (a) 로컬 단서 생성기(Qwen/4090) — 온디바이스 구축 축, 비용 0
- (b) **학습된 생성기**: 자기 질의 스트림으로 SFT/DPO (rejection sampling — 좋은
  단서 = 실제로 회수를 성공시킨 단서, 우리 로그가 라벨). 이게 3막의 학습 컴포넌트.
- (c) β 오염 하 강건성: 단서 색인이 오염 압력에서 열화를 완화하는가 (β와 합류).

## CV-2 — Memory OS 위계 검증 (아키텍처 주장, 별도 트랙)

- **무료 로그 재생 분석 (즉시)**: 기존 full-500 결과에서 캡슐 예산 b별
  "fast-path 충분율"(근거가 top-b 안에 있던 질의 비율) 곡선 산출 → 자동주입/도구폴백
  비율의 비용-정확도 프런티어. 새 실행 불필요.
- **에이전틱 시뮬레이션 (후순위)**: pure-A(도구 강제) vs pure-B(캡슐만) vs hybrid —
  도구 미호출 실패율 실측. Stage 2 통과 후에만.
- **실사용 계측 (제품 접점)**: prepare_context_autopilot에 적중 로깅 추가 — 도그푸드
  자연 발생 적중률 (원 어젠다 E3의 부활). 실행 세션과 협의 항목.

## 산출물 매핑

- Stage 0–2 통과 → 3막 논문 골격 확정 ("Prospective Indexing for Agent Memory")
- Stage 0 사망 → 3막 폐기, β 전념 — 사망 보고서도 field-map에 기록 (α 전례)
- CV-2 로그 재생 → PRD의 Memory OS 섹션 근거 숫자

## v1.1 수정 (2026-07-18, Stage 0 결과 확인 전 — unblinding 이전 적법 수정)

자기 적대 검증(red-team)으로 발견된 결함 5건과 수정. **v1.0의 Stage 0(실행 중)은
탐색용으로 강등, 판정 비구속.** 구속력 있는 판정은 아래 Stage 0-v2가 가진다.

1. **회수 단위 불일치**: 단서는 포인터지 내용이 아님 — 단서 적중 ≠ 증거 전달.
   → 의미론 확정: **단서는 색인 전용, 반환 페이로드는 피지시 세션의 내용(관찰/턴),
   reader 슬롯은 내용 기준 회계.** 전 단계 공통.
2. **벤치마크 순환성**: LongMemEval 질문 자체가 LLM이 세션에서 생성 — 단서 생성이
   출제 과정의 준-복원일 위험. → 한계 명시 + Stage 3에 비유도 질의원(도그푸드 실질의
   로그, E3 계측) 필수 편입 + 주장 강도 하향.
3. **킬 논리 누수**: zero-shot 실패로 학습된 생성기를 죽일 수 없음(분포 접근 부재).
   → 생성기에 분포 사전 주입: 타 인스턴스 질문 few-shot (자기 질문 비접근 유지).
4. **천장 미보정 기준**: 절대 +5pp는 baseline 천장에서 불가능할 수 있음.
   → 기준 교체: **headroom 대비 오류 감소율 ≥25% AND 쌍대 Wilcoxon p<0.05,
   카테고리 층화 보고** (전체 평균의 천장 왜곡 방지).
5. **빠진 강적**: read-time 질의 확장(HyDE류)이 같은 이득을 낼 수 있음.
   → Stage 0-v2에 read-time 확장 군 추가. 판정 분기: 전향적 > read-time이면 효과
   novelty, 동등이면 경제성(쓰기 1회 vs 질의당) 주장으로 정직 강등, 미만이면 킬.

### Stage 0-v2 군 구성 (5군, dev-42)
baseline / placebo(셔플) / **cue-prior**(분포 few-shot 단서, content-delivery 의미론)
/ **read-expand**(질의 시점 HyDE 확장) / cue-prior+read-expand(가산성 확인)
