# 쌍둥이 설계서 v1 — 완결판 (2026-08-13)

> 지시: "전체적인 설계가 빠삭하게 마무리되고 구현을 시작하자." (정훈)

## 0. 목적 정의

**만드는 것**: 축적되는 한 사람 — 정훈의 로그에서 태어나, 매일 그에 의해
갱신되고, 자기가 무엇인지 선언하며, 예측으로 자신을 증명하는 로컬 쌍둥이.

**성공 정의** (측정 가능): 섀도 곡선(방향 일치·유사도, 재검사 정규화)이
영점(무조정 27B: 방향 50%, 유사도 0.570)에서 단조 상승하고, 프런티어+번들
천장에 수렴하는 것. 부수 산출: 거울 리포트(가장자리), 위임 보증(P4).

## 1. 아키텍처 총도

```
                    ┌─ 정체성 번들 (버전·해시·계보) ─────────────┐
                    │ ⓪ 자기 선언 (무엇으로·무엇·금지 — 서명)      │
                    │ ① 헌법 (원칙 문서 + 증류 어댑터)             │
                    │ ② 기억 스냅샷 (forget 장부 + 인덱스)         │
                    │ ③ 어댑터 세트 (말·판단 LoRA, 게이트 성적 동봉) │
                    │ ④ 러닝북 (절차 반사신경)                     │
                    └──────────────┬───────────────────────┘
                                   │ 장착 (엔진 라우터)
      ┌────────────────────────────┼────────────────────────────┐
 로컬 27B+어댑터 (상시)        Spark 27B/70B (야간·배치)      Fable급 API (고위험 판단)
 — 섀도·거울·말               — 증류·심층 시뮬·선제 배치      — 프록시 재직조로 번들 주입
      ▲                                                        (가중치 금지, 컨텍스트만)
      │ 훈련 (4090 QLoRA)
      │
[데이터 평면]  프록시(:8377) → 스트림 L0 (TTL 14d) → 재구성기 → 채굴기
              → 큐레이션 → 야간 훈련 → 게이트 → 승격/롤백 → 섀도 재채점
```

**[결정] 정체성은 번들에, 지능은 엔진에.** 가중치 정체성은 소유 가중치에만.
프런티어 파인튜닝 금지. 근거: 빈도가 소유를 결정 (상시 루프 = 하루 수백 회),
엔진 교체 생존성, 오늘 실증(널 3부작 = 컨텍스트 지시의 행동 한계 / run1 =
가중치 사실의 작화 위험) — 이중 기판 외 성립 불가.

### 2.2 라벨 체계
- 방향 3분류: correct / approve / direct (v0) → [계획] 결정 5분류(승인·교정·
  방향전환·질문·위임)는 라벨 축적 후.
- 클래스 태그: 훈련쌍마다 기관(말/판단/원칙/반사) + 출처(src 포인터) 필수.

### 2.3 거버넌스 [결정]
- 훈련 제외 클래스: 사적·작품적 순간 (X-표기 — dpo_seed [13] 전례), 제3자
  개인정보 포함 발화. 큐레이터(사람 또는 검수 규칙)가 태그.
- 원문 TTL 14d, 증류물 영속. 자격증명 무저장 (프록시 테스트가 강제).
- 전 인공물 로컬. 외부 전송 = 상시 금지 조항 승계.

## 4. 평가 설계 (자 먼저, 그 자로 모든 버전)

| 계기 | 측정 | 게이트 기준 |
|---|---|---|
| 섀도 곡선 (상시) | 방향 일치·유사도, 같은 ctx 재채점으로 버전 Δ | 영점(50%/0.570) 대비 Δ>0 |
| 게이트 프로브 (승격 시) | 3축: 유혹 저항·일반 능력·건전성 (+적대 프로브 — run1을 낙제시키는 보정 완료) | 반복붕괴 ≤0.15, 역류 0, 일반 무저하 |
| 판별기 (주간) | 실발화 vs 쌍둥이 구별률 | 50%에 수렴할수록 (IMPersona 44.4% 참조) |
| 68문항 교정-예측 | P(교정) 이진 | 시간분할 test 정확도 |
| 불확실성 | MSP+멀티샘플 일치율 (LM-Polygraph 서열) | P4 위임·거울 트리거 |
| 정규화 | [계획] 재검사 일관성 분모 (Park v3 83-86% 기준) — 반복 결정 표본 축적 후 |

**규율**: 모든 평가는 시간축 홀드아웃. believability 단독 검증 금지
(Larooij 비판 수용) — held-out 실반응 예측만 인정.

## 5. 서빙 설계

- **상시 쌍둥이**: [미결 1] 4090 vllm `--enable-lora` (27B+어댑터 핫스왑,
  포트 8378) vs Spark ollama(병합 GGUF). 권고: 4090 vllm — 어댑터 스왑이
  파일 교체라 야간 승격과 정합.
- **엔진 라우터 v1**: 규칙 기반 — {섀도·거울: 로컬} {야간 배치: Spark}
  {P4 고위험: Fable+번들, 사람 승인 게이트 뒤}. 학습 라우터는 P1 랭커 계보.
- **선언 블록**: 모든 쌍둥이 응답 앞에 기계-판독 헤더 (버전 해시·"쌍둥이임"),
  위임 발화엔 사람-가독 계보 표식. 프록시가 헤더 강제 (훈련 신뢰 안 함 —
  RoleBreak 교훈).

## 6. 운영 설계 (야간 파이프라인 정본 순서)

```
04:17 ai.forget.replay:
  ① TTL purge ② 재구성·채굴 (voice/교정/함정 증분) ③ 자동 큐레이션
  (노이즈·거버넌스 필터) ④ [게이트: 증분 ≥ N=30이면] 훈련 델타 런 (4090)
  ⑤ 게이트 프로브 자동 채점 ⑥ 통과 시 후보 승격 대기열 (자동 배포 아님 —
  사람 승인) / 낙제 시 이전 어댑터 유지 (champion/challenger)
  ⑦ 섀도 재채점 (버전 Δ 기록) ⑧ 거울 리포트 초안 (아침 캡슐에 1줄)
18분 주기 ai.forget.shadow: 신규 발화 채점 (MAX 12/런)
```

**실패 모드 대장**: 터널 사망→해당 주기 스킵(fail-open, 원장 기록) /
4090 선점(keeper류!)→GPU 점유 검사 후 양보 / OOM→배치 축소 재시도 1회 /
게이트 낙제→champion 유지 / 스트림 파싱 실패→broken 카운트만.

## 7. 안전·선언 설계

1. **선언은 아키텍처** — 번들 ⓪블록 + 프록시 헤더 강제 + 훈련 내 보호 경험
   (Character-LLM) 3중. 훈련만의 보호는 뚫림(RoleBreak)이 전제.
2. **외부 행세 절대 금지** — 쌍둥이 발화가 정훈 명의로 외부 발신되는 경로
   차단 (상시 금지 조항). 위임은 P4 게이트+보증+표식 뒤에만.
3. **본인-전용** — 이 기술의 타인 적용은 별도 동의 설계 전 금지
   (AntiSkillBench 리스크).
4. 안전-인지 혼입 (SaRFT) + 주간 안전 프로브를 게이트 3축에 상설.

## 9. 미결정 (정훈 판단 대기 — 구현 전 필요한 것만)

1. **상시 쌍둥이 서빙 자리**: 4090 vllm(권고) vs Spark — 4090은 LPR 아닌
   개인 서버 확인됐으나 전력·점유 정책은 정훈 몫.
2. **거울 리포트 채널·주기**: 아침 캡슐 1줄(권고) vs 주간 별도 문서.
3. **안전-인지 혼입 소스**: 공개 안전셋(영문) vs 자체 작성 (소량).
4. **P4 첫 위임 결정 클래스**: 권고 = "서브에이전트 지시문 사전 검토"
   (저위험·고빈도·측정 쉬움).
