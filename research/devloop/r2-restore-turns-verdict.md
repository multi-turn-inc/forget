# R2 판별 — restore_turns "rt=1 시대"의 정체 (사이클 106, 2026-08-12)

집행 근거: audit-100 R2 → amendment-105 §4 배정 ("c106+ 관측 사이클 후보").
계기: `research/devloop/scripts/c106_r2_rt_recount.py` (읽기 전용).
질문: rt=1 시대(c3~c20)는 (i) 실제 1턴 복원이었는가(실퇴행) / (ii) 계상 정의가
달랐는가(자[尺] 교체).

## 판정 — **(ii) 자 교체 확정, (i) 실퇴행 반증**

rt=1 시대의 세션들은 오늘과 **동일한 턴 구조**였다: 턴1 = 헌장·지시서 Read(+초기엔
ToolSearch), 턴2 = get_task_state + metrics tail + git, 턴3 = 첫 유효 행동.
현행 정의로 재계수하면 c3~c20 18표본 전부 **3**(17건) 또는 **4**(감사 모드 c20) —
원장의 1과 일치 **0/18**. 1턴 복원은 한 번도 없었다. 무엇도 3턴을 "강제하게 된" 적이
없다 — **구조 바닥 3은 c3부터 이미 참**이었고, 규약 ④(c91)는 그 바닥을 성문화했을 뿐이다.

## 방법

- **현행 정의**: restore_turns = 첫 유효 행동이 포함된 턴의 순번. 턴 = 어시스턴트 API
  응답 1개(트랜스크립트 message.id 묶음). 유효 행동 = 복원 집합(헌장·지시서·CLAUDE.md·
  metrics·step0 스크립트 Read, ToolSearch, get_task_state/prepare_context_autopilot,
  git status/log, metrics tail류, c48 실행, MCP curl 폴백) 밖의 첫 도구 호출.
- **앵커**: f2_ledger_from_transcripts.py 방식 재사용 — 트랜스크립트 [birth, mtime]
  창의 `loop(cycle N)` 커밋. 복수 사이클 걸침(대화형)은 제외.
- **계기 교정 (원칙 1 대조군)**: 원장이 현행 자로 쓰인 c95~c105에 같은 계수기를 먼저
  적용 — **일치 11/12**. 유일 불일치 c100(재계수 6, 원장 3)은 적대 감사 모드: metrics
  정독이 그 모드에선 복원이 아니라 작업 자체다(도구 표면 분류기의 의도 맹점, 아래 한계).

## 함의 — LOOP.md "목표: 1"

목표 1은 1대 자(복원 조회 턴 수) 아래에서 설정된 수다. 현행 자로는 **관측 전 구간에서
한 번도 달성된 적이 없고**, 규약 ④ 준수 시 구조 바닥이 3이다. A-105.1의 잠정 문면
("규약 ④ 채택(c91) 이후 구조 바닥은 3")은 이 실측으로 강화된다: 바닥 3은 c91 이후가
아니라 **관측 가능한 전 역사에서 참**이다.

## 후속 문면안 A-106.1 (게이트 — 정훈 승인 대기, 적용하지 않았다)

A-105.1(게이트 큐 재중)의 병기 문면을 다음으로 교체 상신한다. 대상: LOOP.md 자기
지표 절 `restore_turns` 항.

> `restore_turns` — 세션 시작→첫 유효 행동까지 턴 수. **자[尺] 주석(c106 판별,
> r2-restore-turns-verdict.md)**: 원장 c3~c39는 1대 자(복원 조회 턴만 계상),
> c40~c61은 2대 자(복원 소요 턴 계상)로 기록됐다 — 현행 자(첫 유효 행동 턴 순번)와
> 산술 비교 불가. 현행 자·규약 ④ 아래 구조 바닥은 3이며, 3 상수는 '준수'의 확인일
> 뿐 개선·퇴행의 표본이 아니다. 목표는 "규약 준수 시 3, 위반·재구성 발생 시만 초과"로
> 읽는다. (구 "목표: 1"은 1대 자의 수로, 현행 자에서는 정의상 도달 불가.)

판별 전 목표 변경 금지(R2)는 판별 완료로 해제 조건 충족 — 이 문면은 판별 **결과**에
근거한 목표 재정의 제안이며, 채택 여부는 정훈 게이트.
