## 종결 (2026-08-01 오후) — 이 어댑터는 폐기, 공식 하네스로 이관

fastembed 재런 결과: forget 80/422 (19.0%) vs BM25 89/422 (21.1%),
불일치 53문항(22 vs 31), McNemar p≈0.27 — 유의하지 않음.

세 가지 교훈으로 마감한다:
1. **임베딩은 병목이 아니었다** — 일반 294문항에서 해시런 19 vs fastembed런 18.
   "1차 무효는 해시 폴백 때문" 가설은 기각. 근거 예산(절단 트리 8청크)이 지배 변수.
2. **자작 채점은 런 간 비교가 안 된다** — -abs 128문항이 1차 포화(128/128)↔2차
   62/128. 심판 비결정성 앞에서 런 내 비교만 유효했다.
3. **공식 RAG 베이스라인(42.8~51%) 대비 우리 어댑터는 19~21%** — 벤치가 아니라
   어댑터를 측정하고 있었다. 진단·수리 대신 폐기가 옳다: 공식 하네스의 Memory
   인터페이스(insert/query)에 forget 모듈을 끼우면 어댑터 변수가 통째로 소거되고,
   숫자는 논문 표·리더보드와 직접 비교 가능해진다.
