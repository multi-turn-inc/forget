# 무결성 규약 — "개주작이 아님"의 증명 체계 (2026-08-13)

> 계기: 정훈 "이 실험들이 개주작이 아니라는 건 어떻게 증명하지?"
> 첫 적용: 섀도 A/B에서 시간 누출 벡터를 자기 적발 → 중단 → 컷오프 재실행.
> 원칙: 증명은 선의가 아니라 **구조**에서 온다 — 조작할 수 없게 만들거나,
> 조작하면 들키게 만들거나, 둘 다.

## 주작 벡터 전수 목록 × 봉쇄

| # | 벡터 (어떻게 조작되나) | 봉쇄 | 상태 |
|---|---|---|---|
| 1 | **시간 누출** — 예측 대상보다 나중에 생긴 정보(기억·문서)가 입력에 섞임. 답이 채널로 샌다 | 인출에 `created_at < 대상 ts` 컷오프 강제. 평가셋은 시간 분할만 | ✅ 오늘 자기 적발·봉쇄 (섀도 A/B) |
| 2 | **자기 채점 오염** — 정답지를 만든 자가 응시 | 채점자가 만든 셋으로 그 채점자를 평가하지 않는다 (임대천장 8건이 이 이유로 회고셋 응시를 자진 무효화). 미래-발생 라벨만 유효 | ✅ 규약화 |
| 3 | **사후 선택 (cherry-pick)** — 잘 나온 턴·시드·런만 보고 | 표본 선택 규칙을 실행 **전에** 코드에 고정 (예: "최근 N턴 전부"), 원시 산출물 전행 append-only 보존, 실패 런도 원장에 (c31→c39 후퇴 공개 전례) | ✅ 관행 → 규약화 |
| 4 | **다수클래스 착시** — 기저율을 이기지 못하는 정확도를 성과로 포장 | 모든 분류 지표는 다수클래스 대비 Δ로만 보고 (R̂ 영점 70%→"신호 없음" 분해 전례) | ✅ 오늘 적용 |
| 5 | **지표 게임** — 채점기(임베딩·정규식)가 무른 것을 이용 | 지표 2계 이상 병행 + **원시 예측-실제 쌍 전문 공개** — 최종 심급은 사람 눈. 주간 표본 검수 | ✅ (쌍 전문 저장 중) |
| 6 | **사후 가설 (HARKing)** — 결과 보고 가설을 소급 작성 | 선등록 원장 (predictions.jsonl / P-원장) — 가설·게이트·사전확률을 결과 전에 기록. 위반 시 "사후 등록 할인" 명기 (P32 전례) | ✅ 문화 확립 (선등록 101건, 67% 반증) |
| 7 | **재현 불가** — 같은 실험을 다시 못 돌림 | 코드·시드·데이터 스냅샷을 git에 (해시 = 지문), 검증 스크립트 동봉 (adaptive_v3/verify.py 전례) | ✅ 관행 |
| 8 | **타임스탬프 위조** — 선등록 시각 자체의 조작 의심 | git 커밋 체인이 순서 증명 (커밋 해시는 소급 수정 시 연쇄 파괴). 강화 옵션: 주기적 외부 앵커 (공개 저장소 푸시가 제3자 타임스탬프) | ⚠️ 로컬 커밋만 — 외부 앵커는 푸시 시 |
| 9 | **환경 오염** — 모델이 훈련에서 평가셋을 봄 (베이스 모델 오염) | 우리 평가 라벨은 사적 로그·미래 발화라 어떤 베이스의 사전훈련에도 없음 — 개인-예측 과제의 구조적 이점 | ✅ 구조적 |
| 10 | **에이전트(나)의 이해 상충** — 시스템 제작자가 성적을 보고 | 최상위 봉쇄 = **전향 예측**: 예측을 실발화 도착 **전에** 기록하면 조작 원리적 불가 (섀도 v1 = 선예측 모드). 사후 채점은 항상 "회고" 딱지 | 🔜 섀도 v1 과제 |

## 증명력의 서열 (아래로 갈수록 강함)

1. 회고 채점 (현 섀도 v0) — 컷오프·선택규칙 갖춰도 "회고" 딱지 필수
2. 시간 분할 홀드아웃 (훈련 과거 / 평가 미래)
3. **전향 선등록 예측** — 도착 전 기록, git 앵커 (지향점)
4. 제3자 재현 — 코드+데이터로 남이 재현 (공개 시점의 기준)

## 상설 의무

- 새 실험 스크립트는 벡터 1·3·4를 코드 수준에서 통과해야 발사 (체크리스트)
- 모든 성과 보고에 해당 실험의 "회고/홀드아웃/전향" 등급 명기
- 오염 발견 시: 즉시 중단 → 원장에 자백 → 봉쇄 → 재실행 (오늘의 절차가 전례)
