0.5.0 — the honesty release

A month after the dial, the engine learned three things the dial could not teach it: where a fact came from, when a fact should not be acted on, and how to forget on purpose. The trigger was a real incident — one mis-ingested lecture transcript put a false deadline and a false affiliation into the vault and they came back ranked first. Every change below either closes that hole or was already in the tree waiting for a release.

### Provenance is structural, not advisory
- **Action-grade gate.** A non-green fact that carries a date, deadline, time or amount returns `trust.gate = "confirm_required"` at read time.
- **Machine-origin quarantine.** Facts from transcripts, recordings, ASR, OCR, crawls or scrapes — spoken by neither the user nor a tool — enter `quarantine.status = "pending"`. Hidden from `search_memories` unless `include_quarantined: true`. `confirm_memory` releases both.
- **Provenance-weighted search.** green ×1.15, action reports ×0.85, superseded excluded; `score_breakdown.provenance` shows the factor. Sealed by a replay test of the original contamination.

### Learned forgetting
- Decay bank feeds the v2 ranker · series supersede at write time · capture hygiene lane · task-inertia channel · situation seat (`situation_recall`) · temporal neighbours (EM-LLM port).

### Consolidation as a daily organ
- Nightly launchd heartbeat (05:23) with backup, three-day cap, handle-preservation gauge and `--restore DAY`. Compiler ladder v0, echo breaker, deterministic track routing (gate calls 62 → 12).

### Absence answer (v0)
- `GET/POST /ask/{handle}` answers on the owner's behalf, in the owner's first person, and says "I don't know" when the basis is missing. Signed receipt per answer, 20 questions/hour/IP, shops in `~/.forget/absence.json`.

### Memory Agent market (prototype, locked by default)
- Products · quotes · grants (30-day default expiry) · Ed25519 receipts · statement endpoint. MCP tools `catalog_search`, `product_quote`, `grant_create`, `grant_revoke`, `agent_consult`, `receipt_verify`; all 403 without an agent-bound Bearer credential and `profile=codex|claude`. Team ledger: `team_read` / `team_note`.

### Codex · proxy · connect
- `prepare_codex_context`, Codex tool profile, outcome labels on Codex `Stop`.
- `forget-proxy`: `/healthz`, timestamped diagnostics, upstream errors relayed verbatim.
- **forget-connect 0.6.0**: zero-config proxy wiring on macOS (launchd + watchdog, chains an existing gateway with `--upstream`, withdraws its override after three failed health checks), skills/plugin installer, `forget_bstate` hook, progress recall on Bash failures. Requires server 0.5.0.

### Numbers
- LongMemEval (S, n=500): best config **81.8%**, reproduced three times (81.8 / 82.4 / 81.8); fully-local pipeline **76.2%** (76.8 / 76.4 / 75.2). Harness and every run file in `research/longmemeval/`.
- Handoff error across a forced compaction: **0.8% vs 20%** (consolidation vs whole-context summarisation) — synthetic relay task, n=10, single compaction. Stated as measured, not generalised.

Install: `pip install -U "forget-ai[server]"` · `npx forget-connect@0.6.0`
