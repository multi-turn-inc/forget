# 계산되는 감정 등가물 — 선행 지형과 벤치 실험 (P-E 시리즈)

2026-08-29. 발단: 정훈 "결국 감정이 키 포인트이려나" → "LLM 추출은 어불성설"
→ "벤치마크로 승부, 4090에서". 헌장(memory-intelligence-design.md)의 자매 문서.

## 1. 원칙 (이 시리즈의 헌법)

감정 등가물은 **읽는 것이 아니라 계산되는 것** — LLM더러 텍스트에서 감정을
읽게 하는 것은 3중 오류(자기보고 순환·사후 시점·범주 착오). 정본 신호 4종:

| 신호 | 뇌 | 계산 (LLM 판정 0) |
|---|---|---|
| 놀람 | NE·예측 오차 | teacher-forcing NLL(서프라이절) · [전망] 대조 |
| 막힘 | 좌절 | 재시도 연쇄·에러 체인·재방문 루프 — 로그 산수 |
| 해소 | 도파민 | 상태 전이(실패→성공, 미결 닫힘) |
| 경계 | 편도체 | 금지·파괴 근접 — 결정론 |

## 2. 선행 지형 (2026-08-29 조사)

- **놀람-게이팅 갈래 (활발)**: [Titans](https://arxiv.org/pdf/2501.00663)
  (그라디언트=놀람, 과거+순간 분해, 망각=가중치 감쇠 — 정훈 기학습) ·
  [EM-LLM](https://arxiv.org/pdf/2407.09450) (토큰 서프라이절로 일화 분절,
  동결 모델 작동) · [Nemori](https://arxiv.org/html/2508.03341) (예측 오차가
  의미 증류를 결정 — 모토 논리의 시스템화) · [로봇 놀람-게이팅]
  (https://arxiv.org/html/2606.03787v1) — **교훈: 놀람은 확률 소음을 무시하는
  특징 공간에서** (픽셀의 나뭇잎 문제 = 우리 axtree의 래핑·ID 문제).
- **어텐션-사용 갈래 (경합)**: [Jain & Wallace](https://aclanthology.org/N19-1357/)
  경고 → 최신은 [정규화 어텐션 비율](https://arxiv.org/pdf/2501.01059) ·
  [로짓 기여도(LOCOS)](https://arxiv.org/pdf/2607.01002). P-A 라벨러 업그레이드
  경로 = raw 어텐션이 아니라 로짓 기여도.
- **감정 태깅 갈래 (주류가 게으름)**: Generative Agents LLM 채점 1~10 ·
  [SCM ValueTagger](https://arxiv.org/pdf/2604.20943) LLM-유래 감정가 —
  어불성설 경로. [ACT-R식 아키텍처](https://dl.acm.org/doi/10.1145/3765766.3765803)가
  "감정 돌출 미모델"을 공백으로 자백.

**빈 곳 (정훈 동의)**: 갈래 1과 3이 서로를 모른다. 계산된 다신호(놀람+행동
역학)를 지속 에이전트 기억 수명주기(쓰기·리플레이·활성도·**검색 좌석**)에
배선한 곳 없음. 특히 행동 신호(막힘·해소)는 전무 — 전부 토큰 놀람뿐.

**자기 몸 논거의 정밀화**: logprob는 오픈모델 API도 노출(놀람의 절반은 API
가능). 몸이 필수인 것 = 어텐션/로짓 기여도·그라디언트. 행동 신호는 몸 불요
(로그 산수). GLM-5.3-Flash 서빙은 신호 실증 **후**의 몸 업그레이드 결정.

## 3. 왜 LME-V2인가 (원장 회고 검증 대신 — 정훈 결정)

- 원장 회고는 n=1 자기참조 — 설득력 한계.
- LME-V2는 우리 계기 완비: 소음 바닥(5.0/15.8/0.0pp)·안정 표적 프레임·
  base 2런 기준선(같은 날 재사용 조건 주의 — 팔 런은 base와 같은 날 필수).
- 궤적 = 에이전트 경험이라 **행동 신호까지 계산 가능한 유일 벤치**.
  gotchas(F6, 0.379~0.414)가 막힘·해소 신호의 자연 과녁.

## 4. P-E-1 등록 (숫자 보기 전 고정) — 0단계: 신호 판별력

**GROUND 교훈(기전 발동 미확인 설계 금지) 집행 — 팔 실행 전 신호부터.**

- 질문: 계산 신호가 **정보 가치 있는 슬라이스를 질의 없이 가려내는가.**
- 방법: subset60의 gold 함유 슬라이스(정답 문자열 매칭 — F4 부검 코드 재사용)
  vs 동일 궤적 무작위 슬라이스, 신호 2종의 판별력(AUC):
  ①서프라이절 — mlx 9B teacher-forcing NLL, **행동/전이 수준 특징 공간**
  (axtree 원문 아님 — 로봇 교훈): 상태 i−1까지의 행동열 조건 하 상태 i 행동열의
  평균 NLL ②행동 신호 — 궤적 내 재방문 루프 근접도·오류 흔적 근접도(산수).
- 예측: 서프라이절 AUC ≥ 0.60 (gold가 고놀람 쪽) · 행동 신호는 gotchas 유형
  gold에서만 AUC ≥ 0.60, 타 유형 무판별(≈0.5)이어도 등록 통과(과녁 특이성).
- 판정: 어느 신호든 AUC ≥ 0.60 → 1단계(좌석 배정 팔) 등록. 둘 다 < 0.55 →
  "질의-독립 내재 가치" 가설 기각, 신호는 쓰기 게이트 전용으로 강등 재설계.
- 비용: $0 (맥 mlx 9B + 산수). 채점 호출 없음.

## 5. 1단계 예고 (0단계 통과 시 등록 문면 고정)

병합 좌석에 질의-독립 내재가치 축 — 고놀람 보장석(M-C1 전례) 또는 MMR
동률깨기. 판정은 안정 표적 프레임 + 같은 날 base 재런.

## 6. P-E-1 0단계 판정 (2026-08-29) — 기각 · 부호 반전 발견

실측: 서프라이절 AUC **0.374**(gold NLL 1.018 vs 대조 1.718 — gold가
**저놀람**) · revisit 0.417 · error 0.500. 등록 문면(둘 다 <0.55)대로
"내재가치=고놀람" 가설 기각.

**탐색적 발견(주장 안 함 — 재현 대상)**: 역방향 판별 1−AUC=0.626.
해석: non-abs gold = 환경 규칙성 = 순조로운 표준 워크플로의 순간(저놀람).
고놀람 = 에이전트가 헤매던 소음. CLS 사상: 의미(규칙성)는 저놀람에,
일화(예외)는 고놀람에 산다. 교란 후보 공시: gold 상태가 "결과 화면"이라
행동이 단순(저NLL)일 가능성 — 통제 필요.

## 7. P-E-1b 등록 (숫자 보기 전 고정) — 서프라이절 부호 가설

- 가설: 서프라이절의 기억-가치 부호는 **정보 유형이 가른다** —
  규칙성(non-abs)형 gold는 저놀람, 예외(gotchas)형 gold는 고놀람.
- 방법: gotchas web 15문항 gold 슬라이스(정답 매칭, 채점 무관이라 오염
  런과 무관) vs 동일 궤적 대조 — 동일 파이프라인. + 교란 통제: 행동
  토큰 길이를 공변량으로 병기(길이 상관 |r|>0.5면 결과 보류).
- 예측: gotchas 서프라이절 AUC ≥ 0.60 (정방향) AND non-abs 역방향 재확인.
- 판정: 둘 다 성립 → 서프라이절 = 유형 분류 축 채택, 1단계는 "고놀람
  좌석"이 아니라 **유형별 부호 적용**으로 재설계. gotchas도 무판별 →
  행동-수준 서프라이절 접근 종결(특징 공간 재설계로만 재도전).
- 비용: $0 (mlx 재계산).

## 8. P-E-1b 판정 (2026-08-29) — 기각 · 행동-수준 서프라이절 접근 종결

실측: gotchas 서프라이절 AUC **0.448** (gold NLL 0.968 vs 대조 0.768 —
평균은 높은데 AUC<0.5 = 소수 롱테일이 평균을 끌고 다수는 역방향). 길이
교란 통제 통과(r=0.029). 등록 문면대로 **행동-수준 서프라이절 접근 종결**.
non-abs의 역방향(0.626)도 gotchas에서 재현 안 됨 — 유형 특이적이거나 우연.

**시리즈 교훈 (정직 기록):**
- 질의-독립 "내재 가치" 신호는 이 특징 공간·이 벤치에서 2연속 사망.
  gold는 슬라이스의 내재 속성이 아니라 **미래 질문에 상대적** — 모토의
  "미래에 대한 정보"는 미래 수요 없이 절반만 계산된다. 뇌의 감정 태깅도
  순수 내재 놀람이 아니라 보상 관련성(과제 맥락) 위에서 작동한다.
- 감정 신호의 자리는 **회수 좌석이 아니라 쓰기 게이트·응고 우선순위**
  (P-E-1 등록의 강등 분기 그대로) — 원래 이틀 논의의 자리였고, 벤치
  회수전으로 확장한 것은 데이터가 기각했다.
- 재도전 조건: 특징 공간 재설계(관찰-수준 등) + 수요 조건부 신호
  (질의×내재의 결합)로만. 벤치 점수 이동 시도는 이 라운드 종료.
