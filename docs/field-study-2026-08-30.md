# 야전 정독 (2026-08-30) — 이번 주 담론 5편의 소화

정훈: "깊게 파보자. 이거 다 우리 피와 살이 되는 경험들이잖아."
규율: 원문 정독 + 증거 등급 병기 + 수확/폐기 명시.

## 1. Lemmalog (Datalog 상태 엔진) — 증거 등급 중 (벤치 수치 있음, 원문은 안전장치 오탐으로 요약본 의존)

- 주장: 문제는 망각이 아니라 **무효화의 미전파**. LLM=사실 추출 프런트엔드,
  Datalog=규칙·증분 평가·철회 전파·출처. LongMemEval F1 0.463.
- 우리와의 대조: supersede 사슬·억제 간선·추이 승계 = 같은 문제의식.
  단 우리 간선은 «같은 사실의 신구»만 잇고 **«이 결론은 저 전제에 의존»
  간선이 없다** — 그들의 진짜 우위.
- **수확 (최대)**: 의존 간선 v0 스케치 — 쓰기 시점에 결론 기억이
  metadata.depends_on=[전제 id들]을 갖게 한다. 원천은 이미 있다:
  context_traces가 «결론 기록 직전에 서빙된 기억들»을 안다(인과 후보).
  전제가 침강하면 의존 기억에 «전제 침강» 황색 표지(자동 강등은 안 함 —
  보수, JTMS의 in/out 대신 표지+판독 위임). 계보: Doyle JTMS(1979),
  de Kleer ATMS(1986). → recallbench 장기 명부 등재.

## 2. 명제 동일성 좌초기 (substack) — 증거 등급 높음 (정직한 실패 보고)

- 그의 설계는 미니-forget이었다: 삭제 없는 supersede, 다중 검색+로컬
  리랭커. 좌초 지점: 모순 감지를 구문적 atom 동일성에 걸었고, 그게
  1892년 프레게 이래 미해결임을 뒤늦게 발견. 성급 병합→가짜 충돌의
  양방향 실패 모드.
- **우리의 답이 문헌 이름을 얻었다**: universal schema(Riedel 2013) —
  «동일성 판단을 포기하고 함의를 학습». 우리 실측(7/23 사건 #1:
  임베딩 공간에서 방향은 측정 불가, 영토는 완벽 분리)과 같은 결론의
  학술판. 우리 우회 3종 = ①계보는 쓰기 시점 선언(series/supersede —
  사후 감지가 아니라) ②병합은 가역 ③충돌쌍은 판독 LLM에 현재/구본
  표지로 제시(방향 판단 위임). 댓글 Samuel의 실용안(«관련 기억 소량
  주고 자연어로 모순 잡기»)은 우리 충돌지대 주입 그대로.
- 수확: 읽기 목록 보존(아래) + 에세이 3 소재("130년 난제를 푸는 대신
  가역성을 샀다"). 그의 86편-미독 자백은 우리 «원문 정독» 규율의 반면.

## 3. 계약서 (dev.to) — 증거 등급 낮음 (자기보고, $15 템플릿 홍보 동반)

- 통찰 2개는 진짜: ①규칙은 **출생증명서**(원인 사고)를 지닌다 — 우리
  CLAUDE.md «왜 이 문장이» 절의 독립 재발명 ②**두 번 교정되면 규칙화**
  트리거("세 번째 교정이 오기 전에").
- **수확**: ①컴파일러 불변식 후보 — rule 정본은 원인 사고/사건 참조를
  의무화(현행: 관행) ②승급 경제식 보정 후보 — 사용자-교정 유형 군집은
  MIN_REPEATS 4 대신 **2**로 (교정의 비용이 반복의 비용보다 크다).
  선등록 후 컴파일러 파라미터로.

## 4. Context rot (dev.to) — 증거 등급 낮음 (인용 0, 전부 일화)

- 메커니즘 어휘(주의 희석·중간 손실·자기 오답의 사실화·낡은 상태)는
  유용하나 수치 주장(20% 등)은 무근거 — 인용 금지, 어휘만 차용.
- 그들 처방(새 세션·인계 파일·서브에이전트 방화벽·편집 전 재독)은 전부
  세션 위생 = 우리 캡슐·재부팅 권고·B층의 동형. 차이: 우리는 질서를
  **원장 층에서 세션 간으로** 들고 다닌다(시계열 승계·침강·재부상).
- 수확: 포지셔닝 문장 — «context rot의 해독제가 메모리 레이어다».
  38턴-낡은-스택트레이스 사례 = stale-state의 세션판(우리 병명 체계로
  수렴하는 외부 증언).

## 5. Trajectory 데이터셋 (dev.to) — 증거 등급 중

- 주장: 최종 답이 아니라 행동 전체(관찰·도구·수정·출처·동결 홀드아웃).
  우리 실물: context_traces·per-question 공개·선등록·동결 표적 프레임.
- **수확**: «수정 쌍(correction pairs)을 1급 데이터로 분리 보존» —
  우리 삼각측량 채굴(침묵→정정 쌍)의 데이터셋화. 가중치+컨텍스트 전략
  ("장부는 훈련 신호")의 가장 깨끗한 신호가 이것 — 수면 루프/어댑터
  훈련의 재료로 등재.

## 문헌 지도 (2번 글의 읽기 목록에서 우리 관련만)

JTMS(Doyle 1979)·ATMS(de Kleer 1986) — 의존 간선의 원전 /
universal schema(Riedel 2013) — 동일성 포기·함의 학습 /
microtheories(CYC) — 맥락 분할 / Open KB canonicalization(Galárraga
2014, CESI 2018) / claim matching(2020). hyperintensionality(철학 키워드).

## 등재 처분

1. recallbench 장기 명부: **의존 간선 v0** (트레이스-유래, 황색 표지형).
2. 컴파일러 후보: rule 출생증명서 불변식 + 교정-군집 MIN_REPEATS=2 (선등록 후).
3. 수면 루프 재료: correction pairs 1급 보존.
4. 에세이 소재: ②→«가역성을 샀다», ④→해독제 포지셔닝.

## 후속 측정 (같은 날) — 의존 간선 v0 전제 기각·설계 수정

실측: 신규 기억 400건 전수가 직전-10분 트레이스를 갖지만(100%) 표본 검사
결과 인과 품질 0 — «심심하면 웹서핑» 질의의 서빙 목록이 무관 기억의 전제로
잡힘. **시간 근접 ≠ 의존** (헌장 §2 재확인 — 측정 10분이 팔 하나를 살처분).
수정 등재: 의존 간선은 추론이 아니라 **선언** — ①add_memory에 선택적
depends_on 필드(쓰는 에이전트가 아는 전제만) ②record_context_outcome의
used_memory_ids와 결합(행동 후 자진 신고). 희소하지만 정직 — 밀도는
습관이 만든다. 장기 명부 문면 갱신.
