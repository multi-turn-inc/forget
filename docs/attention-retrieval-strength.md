# 인출 강도를 어텐션 추이로 잰다 — 실험 설계 + 사전 등록 (2026-08-23)

정훈의 가설(2026-08-23): **"인출강도는 어텐션 스코어의 추이를 보면 되는걸수도?"**

## 왜 이게 유망한가

인출 강도의 현행 대리는 decay-LFU(선택 이력)다. 그런데 그것은 **검색기 자신의
행동**을 재므로 순환한다 — 뽑히면 또 뽑히는 부익부. helped/noise 라벨은 순환이
없지만 희소하다(사람 턴 784건에 gold 0, 2026-08-23 실측). 어텐션은 **읽는 쪽**이
주입된 기억을 실제로 참조했는지를 재는, 사슬의 셋째 고리다:

    검색기가 뽑았다 (decay-LFU) → 읽는 쪽이 썼다 (어텐션) → 결과가 좋았다 (라벨)

매 턴 · 매 좌석 · 공짜 · 조밀 — 라벨 희소성 병목을 우회한다.

선행 검증: KV 캐시 축출 문헌이 같은 기전을 토큰 단위로 이미 쓴다.
[H2O (NeurIPS'23)](https://arxiv.org/abs/2306.14048) 누적 어텐션 = 헤비 히터 보존,
[SnapKV](https://openreview.net/forum?id=poE54GOq2l) 관측 창 투표. 우리의 변주는
토큰 → **기억 좌석**, 한 턴 → **시간 축 추이**다.

## 문헌이 경고하는 편향 (설계가 각각 통제해야 한다)

1. **어텐션 싱크·위치 편향** — BOS·앞 토큰이 내용과 무관하게 어텐션을 흡수한다
   ([싱크 서베이](https://arxiv.org/html/2604.10098v1), [위치 편향](https://arxiv.org/abs/2502.01951)).
   → 통제: **좌석 순서 셔플 대조** (아래 P-B). 좌석을 자기 자신과 비교하는 '추이'도
   위치가 고정된 우리 배치에선 자기-대조가 된다.
2. **가중치 ≠ 기여** — ‖α·v‖ 노름이 맞다 ([Kobayashi, EMNLP 2020](https://arxiv.org/abs/2004.10102)).
   → v0은 생 α 누적(H2O와 동일 조건)으로 시작하고, P-A가 애매하면 노름 가중을 v1로.
3. **반복 과대** — 반복 내용이 어텐션을 과점한다 (R-KV 실측).
   → 좌석은 근접중복 제거를 통과한 것만 주입되므로 구조적으로 완화됨.

## 장치

- **몸**: Qwen3.8-27B UD-Q4_K_XL (17.6GB GGUF) @ 연구실 4090 (정훈 지정,
  2026-08-23: "너무 소형모델보다는 바로 결과를 볼 수 있게").
  이 모델은 v4 사적 트랙 리더이기도 해서 이중 용도.
- **수집기**: llama.cpp `cb_eval` 콜백 (imatrix가 쓰는 그 기구). FA를 꺼서
  KQ softmax 텐서를 실체화하고, 디코드 단계에서만 좌석 스팬 위로 접는다.
  프리필의 n² 행렬은 수집하지 않는다 — 답 토큰(질의) → 좌석(키) 질량만.
- **프롬프트**: system = 고정 머리말 + 번호 좌석 K개(기억 텍스트), user = 질의.
  좌석 토큰 스팬은 조각별 토크나이즈로 정확히 계산.
- **자료**: 평가셋 v1 machine_resume 층(실제 used gold 보유) + human_helped 일부.
  좌석 = 그 질의의 조립 후보 (gold 포함, 비-gold 채움).

## 측정치

좌석 s의 **어텐션 질량** A(s) = Σ_{답 토큰 t} Σ_{레이어 l} α_l(t → s의 토큰들),
좌석 토큰 수로 정규화. 질의 내 좌석 간 상대 서열로만 해석한다(절대값 금지).

## 사전 등록 판정 (숫자를 보기 전에 고정)

- **P-A (신호 존재)**: 질의 내에서 gold 좌석의 A(s) 서열이 비-gold보다 높다 —
  AUC > 0.65면 지지, 0.55 미만이면 반증. **비교 기준**: 같은 질의에서
  decay-LFU 점수의 AUC. 어텐션이 이기거나 대등해야 채택 후보.
- **P-B (위치가 아니라 정체)**: 같은 질의를 좌석 순서 셔플로 2회 돌렸을 때
  좌석 서열의 스피어만 상관 > 0.6이면 지지. 낮으면 어텐션은 위치를 재는 것 —
  싱크/위치 편향 소음이므로 기각하거나 노름 가중으로 재시도.
- **P-C (음성 대조)**: 무관 좌석(다른 주제의 실기억)을 1석 섞었을 때 그 좌석이
  하위 사분위면 지지.
- **채택 규칙**: P-A·P-B 동시 지지 → 인출 강도 3항 혼합의 w₂항으로 채택
  (인출강도 = w₁·선택이력 + w₂·주목추이 + w₃·결과라벨), 하나의 몸 텔레메트리로
  상시 수집 설계 착수. 하나라도 반증 → 의미 메아리 v2(임베딩 유사도)가 대리 신호로
  승격, 어텐션은 보류.

## 한계 (등록 시점에 미리 적는다)

- 어텐션은 **주입된 것의 사용**만 잰다. 발굴(검색 천장)은 못 올린다.
- Qwen 27B 한 몸의 결과다 — 채택해도 "이 몸에서"라는 단서가 붙는다.
- gold 자체가 전부-또는-전무 라벨러 산(오늘 수리 전)이라 위양성이 섞여 있다.
  P-A의 AUC 상한이 그만큼 눌린다 — 낮게 나오면 라벨 탓과 신호 탓을 분리해야 한다.
- 닫힌 API 표면(Claude·DeepInfra)에는 이식 불가 — 거기는 의미 메아리 v2가 대리.
