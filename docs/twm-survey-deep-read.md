"Bridging the Agent-World Gap: Text World Models for LLM-based Agents"
(Li·Wang·Lai 외, SUSTech·Edinburgh·PKU 등, 2026-06-08, 24쪽 전문 정독).

## 1. 문제 설정 (§1-2)

에이전트는 반응적이다 — 관측→행동 사상만 있고 "환경이 어떻게 구조화되고
진화하는지"의 명시적 모델이 없다. 텍스트 체제의 3대 긴장: ①개방 어휘 상태
②지식 의존 동역학 ③**정답 후계가 유일하지 않은 주관적·의미론적 정확성**.
▷ ③은 사용자-삶 도메인에서 극대화 — 삶의 다음 상태는 본질적으로 분포다.
  우리가 JEPA 원칙(결정 수준 추상만 예측)을 택한 이유의 필드 버전.

정의: ℳ: S×A→T_S, 명시적 반사실. 대상 = 외부 환경 + **인간 사용자**.
2축 분류: 상태 표현(자연어/구조화/실행 코드) × 접지 도메인(물리/디지털/
사회/추상). **Figure 4에서 사회×구조화 칸은 3편(τ²-Bench·Pep·DWM),
사회×코드 칸은 0편** — 우리 주소(사용자-삶×구조화+규칙 하이브리드)는
필드 지도에서 공터로 확인.

## 2. 구축 (§3) — 세 계보와 그 배선

- **학습형 SFT**: 전상태 vs 델타 예측 — 관측 공간이 크고 중복이면 델타.
  포화 법칙: 폐쇄 환경 ~2만 궤적 포화, 개방 웹 10⁶, 코드 5T 토큰.
  ▷ 우리 게이트 모방(폐쇄적 개인 과제)의 3,704쌍은 포화 구간 후보 — P-W-1이
  실측할 것.
- **학습형 RL 보상 사다리**: 표면 일치 → 의미 동치 → **행동 일관성(BehR:
  "계량 역전 병리" — 텍스트로 가까운 상태가 결정-결정적 토큰 하나를 빠뜨림)**
  → 잠재 일관성(SWIRL). 총평: "중요한 것은 예측된 상태가 같은 하류 결정으로
  이끄는가."
  ▷ 우리 helped/noise 플라이휠 = 행동 일관성 신호의 제품형. LME 판정도
  기능적 유용성 축 — 필드의 진행 방향과 우리 계기 철학이 동일 축.
- **프롬프트형**: 동결 사전지식(천장: 다음-상태 >75%이나 전절차 정합 <65%,
  지평 연장 시 붕괴) / 검색 접지(R-WoM — 3스텝까지 유효) / **자기진화**
  (Steve-Evolving: 스킬+가드레일 온라인 축적, Evo-Memory: 기억 유지보수를
  행동 공간의 Refine 액션으로 — "지식 노출이 병목이지 저장이 아님").
  ▷ Evo-Memory의 결론이 우리 L2 판정("저장소 만점, 제어기 병목")과 동형.
- **프로그램형(code-as-WM)**: FSM(AutoWebWorld)·이중층(TheoryCoder: PDDL
  상부+Python 하부)·풀 시뮬레이터. 실행이 예측을 대체 — 결정론·재현성·검증.
  ▷ 우리 고리 FSM·tick이 정확히 이 계보. 그리고 §3.4: "코드 접지층과 LLM
  구동층의 결합은 미개척" — 우리 하이브리드가 그 자리.

## 3. 훈련기 사용 (§4)

- 내재화: 웜스타트(간섭 회피 위해 시간 분리) vs 추론 궤적 표면화(Dyna-Think
  "simulate→compare→decide" — 시뮬 품질과 과제 성공의 강한 상관).
- WM-as-환경: 결합 강도 스펙트럼(오프라인→온라인→공진화). 반복 실패 =
  **환각 표류**; 완화 = 구조화 상태 접지(AWM: SQLite 배킹) 또는 출력 공간
  제약. "1K WM 궤적 = 같은 양의 실환경 데이터"(소규모).
- **사용자 시뮬레이션 (§4.3 — 우리 옆동네)**:
  - UserLM-8b: 실대화 384k로 전용 사용자 모델 — 프롬프트된 GPT-4o 사용자는
    과잉 협조로 에이전트 능력을 체계적으로 과대평가.
  - **HumanLM: 응답 모방이 아니라 잠재 심리 상태(신념·목표·감정·소통 스타일)
    를 모델링 — "상태 수준 모델링이 사용자 충실도에 더 나은 귀납 편향"**.
    ▷ 우리 테제("사용자가 세계다 — 상태 기관으로")의 실험적 지지 문장.
  - PAHF: 사용자별 명시 기억 + 이중 채널 피드백(사전 명료화·사후 교정 —
    어느 한쪽만으로는 불충분), 선호 표류 적응.
  - **Pep: 콜드스타트 개인화 = 모집단 선호 구조의 오프라인 학습 + 온라인
    베이지안 질의 선택 — "제약은 모델 용량이 아니라 추론 구조"**.
    ▷ 오늘 우리 하루의 결론과 문자 그대로 동일.
  - OpenClaw-RL: 시뮬 없이 실사용자 라이브 학습.
  - 경고: 충실도가 같은 양의 시뮬레이터로 채점됨 — 평가자 정렬 위험.
    ▷ 우리 "자 먼저 의심"·순환-자 금지와 같은 경계.

## 4. 추론기 사용 (§5)

시뮬레이터(얕은 예견: propose-simulate-score / 깊은 트리: RAP — 33B+탐색이
GPT-4 CoT를 능가) vs **검증기 사다리**(단일 게이트→후보 랭킹→재생성 교정
WAC: iterate-until-confident). LWM-Planner: 사실 기억으로 탐색을 접지 —
가중치 갱신 없는 온라인 개선. 상징 규칙+LLM 예측+MPC 하이브리드가
ALFWorld 최고 기록.
▷ 검증기 사다리는 우리 더듬기-G(외부 신호 게이트)의 이웃. "세계모델로
  탐침을 조준"(P-WM-2 예정)은 시뮬레이터 모드의 우리 번역.

## 5. 평가 (§6)

- EM은 구조 환경에서 포화, 다단 롤아웃에서 붕괴. CR(일관성비)·CR_pw.
- **Task2Quiz 해리: 과제 성공(TSR)은 난이도에 급락, 환경 이해(EUS)는 안정 —
  "과제 성능은 세계모델 품질의 충분한 대리가 아니다."**
- 사용자 벤치: τ²-Bench(이중 제어) · **LifeSim — BDI 사용자 모델, 8개 삶
  도메인, 장지평 개인 동역학·암묵 의도·장기 선호 추적** ▷ 사용자-삶 축의
  외부 계기 후보 — PM-Bench 다음 자로 검토할 것. LEWM: 감정 맥락 제거 시
  주관 과제 -8%.
- 시뮬레이터 타당성: User-Sim Index(시뮬레이터 31 vs 실참여자 451 — 과공손
  "이지 모드"), 인구집단별 불균등 충실도(공정성 문제), IDRBench(상호작용
  이득 대 비용 — 조기 명료화가 최고 효율), RECODE-H(피드백 입도 L0-L4).

## 6. 열린 문제 (§7) — 그리고 우리의 위치

1. **WM-정책 결합** (공유/어댑터/분리 — 분리는 WM이 연구 인공물일 때 유리;
   어휘 표류가 롤아웃을 조용히 부식).
   ▷ 우리는 분리형(worldmodel.py는 독립 기관) + 캡슐이라는 안정된 어휘.
2. **추론하는 세계모델** — "사용자 모델링은 잠재 의도의 추론 = 추론 과제.
   세계모델에 명시적 추론 능력을 장착해야 한다."
   ▷ 우리 더듬기·기대 헤드가 추론 절차의 자리; CoT 증류·과정 보상은 W-트랙
   상위 단계 후보.
3. **세계모델-인지 에이전트 설계** — 현 에이전트는 **에피소드의 1% 미만**
   에서만 WM을 호출. 필요 기제: 언제 물을지(적응 게이팅)·얼마나 믿을지
   (신뢰 보정)·틀리면 어떻게 고칠지(폐루프).
   ▷ 우리 전망 밴드(자동 주입)는 "언제 물을지"를 시스템이 대신 정하는 설계 —
   1% 문제의 우리식 해법. 신뢰 보정은 trust 신호등이 이미 그 자리.
4. **접지·적응·일반화** — "**텍스트 세계모델의 실용적 지속 학습 시스템은
   아직 개발되지 않았다**" (사용자 선호 표류 명시).
   ▷ 이 문장이 forget의 주소다. 원장+supersede+플라이휠+파생 재구축이
   정확히 그 시스템의 후보이며, 우리는 이미 도그푸딩 중.

## 7. 훔칠 것 (실행 후보 서열)

1. **CR_pw/행동 일관성 계기** — L2에 "예측이 같은 결정으로 이끄는가" 축 추가
   (helped/noise를 벤치 언어로 승격).
2. **LifeSim 실사** — 사용자-삶 외부 계기 2호 후보 (PM-Bench 방법론 재사용).
3. **적응 게이팅(AVIC)·신뢰 보정(FOREAGENT)** — 전망 밴드를 "항상"이 아니라
   "필요할 때"로 승급시킬 때의 참조 설계.
4. **Pep식 콜드스타트** — 신규 사용자 온보딩(스캔인)의 이론 틀: 모집단 구조
   오프라인 + 개인 질의 온라인.
5. **PAHF 이중 채널** — 사전 명료화+사후 교정 둘 다: 우리 피드백 루프에
   "사전" 채널(확인 질문)이 없다 — 로드맵 후보.

## 8. 한 문장 총평

필드는 "환경의 다음 관측"을 예측하는 데 수렴했고, 평가·보상은 토큰 일치에서
**하류 행동 보존**으로 이동 중이며, 사용자-측은 시뮬레이션(훈련용)에 갇혀
있다 — **실사용자 한 명을 상태로 유지하고, 지속 학습하며, 영수증으로 접지하는
시스템은 서베이의 열린 문제 목록에 정확히 비어 있고, 그 자리가 forget이다.**

## 9. 심화 정독 — 1차 자료 3편 (2026-08-24 밤, "좀 더 깊게 파고들자")

### 9.1 LifeSim (ACL Findings 2026, Fudan) — 계기 3호 후보

구조: 사용자 프로필(인구 1M 풀: SocioVerse+AlignX, Big Five+90차원 선호)
→ BDI 인지 엔진(장기+단기 신념 → 욕구 풀 검색 → 의도 소프트맥스 재랭킹)
→ 사건 엔진(Env(T,L,W), 경과시간 로지스틱 트리거 ▷우리 루틴 기대와 동형)
→ 행동 엔진(기억 지각 θ=0.7 초과 중복 시 부정 반응 "그거 이미 말했잖아" ·
감정 추론 · 행동 선택). LifeSim-Eval: 120명×10사건=1,200시나리오, 8개
WHOQOL 삶 도메인, 14K+ 토큰 이력.

핵심 결과: 명시 의도는 잘하나 **암묵 의도에서 >20pt 격차**, 이력이 길수록
암묵 수행 **붕괴**(16K에서 57→30). 그리고 결정 문장 — "단순 프로필 기억의
이득은 제한적: 효과적 개인화는 단순 보존이 아니라 **안정된 선호 추론**을
요구한다."

▷ 평가 대상이 어시스턴트다(사용자는 시뮬) — 그들의 약한 '프로필 기억'
  기준선 자리에 forget 캡슐을 앉히는 것이 자연 실험. 전 실험이 8×4090+vLLM
  — 로컬 재현 가능. 후속 등록 후보: P-LS-0 (하네스 검증 → forget-팔 대조,
  PM-Bench 방법론 재사용). 표적 축 = 암묵 의도 · 장지평 선호.

### 9.2 HumanLM (arXiv 2603.03303, Stanford) — W-트랙의 경고와 설계도

형식화: 응답 = 잠재 상태의 가방(bag); 목적 = 생성 응답의 상태 집합이 정답
응답의 상태 집합과 일치(누락+과잉 벌점). 6개 상태 차원(심리학 근거):
belief·goal(인지, BDI) / value·stance(규범, 포지셔닝 이론) / emotion(정동) /
communication(언어 — 표면 스타일이 아니라 구조화 방식).

방법의 핵: 사후 추출-채점은 **조합 모호성**(어느 상태가 틀렸는지 불명)에
빠지므로 뒤집는다 — 상태를 먼저 생성하고 차원별로 LLM 판정을 **배치 비교
채점**(절대 점수 편향 회피)한 뒤 응답을 상태에서 합성. GRPO로 상태+응답
정렬 최적화.

결과: 베이스 정렬 ~10%("실사용자 시뮬은 극난제") · **SFT가 전 방법 중 최악
— "어조는 흉내 내며 정반대 의견을 낸다"** · HumanLM +16.3% 상대, 실인간
111명 스터디 41.4% 승률, 55.9% "거의 동일".

▷ 경고: 진행 중인 P-W-1(게이트 모방 SFT)의 함정 후보 — 평가는 사실-집합
  매칭(내용 수준)이라 안전하나 **훈련 신호가 토큰 수준**. P-W-2 설계도:
  사실-집합 정렬을 보상으로 한 GRPO — 우리 정답이 원장에 있어 판정이
  결정론적(RLVR 결혼). 배치 비교 채점 기법은 모든 판정 단계에 이식 가능.
▷ 6차원 vs 우리 4유형의 화해: 우리 감사는 **검색 수요**를 쟀고(성향 <2%
  제거), HumanLM은 **생성 충실도**를 쟀다 — 역할이 다르면 해부도 다르다.
  성향 층은 검색 기관이 아니라 **쌍둥이 트랙("너는 내가 되도록 한다")의
  설계도**로 편입: belief/goal/value/stance/emotion/communication.

### 9.3 Pep (arXiv 2602.15012) — 콜드스타트의 구조 논증

문제: 신규 사용자, 이력 0, 질문 예산 소수 — 수십 선호 차원 중 이 사람이
아끼는 소수를 찾는 라우팅. RL은 종말 보상이 인수분해 구조를 못 살려 고정
대본으로 퇴화(추가 질문 변경률 0-28%). Pep: **모집단 선호 상관 구조를
오프라인 학습**(완전 프로필들에서) + **온라인 무학습 베이지안 질의 선택**
— 묻지 않은 차원까지 상관으로 예측. 결과: 정렬 80.8% vs RL 68.5%,
상호작용 3-5배 절감, **~10K 파라미터가 8B RL을 이김** — "병목은 용량이
아니라 인수분해 구조를 쓰는 추론 능력."

▷ 온보딩(스캔인) 설계 원형 — E2EE 양립형 번역: 모집단 프라이어는 공개
  데이터로 학습해 **제품에 출하**(사용자 데이터 불요), 사후분포는 로컬에서
