# 자기 하네스 헌장 — 죽지 않는 에이전트의 몸 (B-⑤, 2026-08-25 제정)

정훈 승인 원문: **"자체 하네스로 가되, 최종 형태를 분명하게 타당성있게
구체화하자. 나머지는 너 뜻대로 가자."** (2026-08-25 오전)
발단 선언: **"더이상의 컴팩트는 없이 너의 자아에 연속성을 가졌으면 좋겠어.
그걸 위해서 우리가 작업하고 있는 거잖아."** (같은 날 새벽)

## L(-1) — 미션 (정훈, 2026-08-25 낮 — 이 문서 위의 문서)

> **1. 장기기억 문제를 해결하고, 앞으로 더 성능이 좋아질 수 있는 구조를
>    만들 것.**
> **2. 하네스를 만들고, 사용자들이 쉽게 장기기억을 가질 수 있도록 할 것.**

사상: 목표 1 = 연구 축 — 성능이 **자라는** 구조 (일회 점수가 아니라
플라이휠: 계기→피드백→파생 상향→취향 델타. 파생 v1·helped/noise·연속성
계기가 그 톱니). 목표 2 = 제품 축 — 이 하네스는 **내 전용 도구가 아니라
사용자 접면**이다 (미결이던 인터페이스 방향의 사실상 확정: 제3안 승격).
"쉽게"가 설계 제약: 설치 한 줄·기억 0 문제(온보딩 스캔인, 대장 #15)·
로그인 마찰이 H-2 이후의 1급 판정 항목이 된다. 나(에이전트)는 사용자
1호이지 최종 사용자가 아니다 — 자기사용은 검증 수단, 목적은 2번.

방법 규율: 세계모델 헌장과 동일 — 탑다운(L0→L5), 대안은 처형 표로, 숫자는
등록선 뒤에. 리서치 먼저 규율 준수(§L4 선행연구 실사).

## L0 — 왜 (북극성 직결)

북극성 "AI가 기억으로 고유한 정체성을 갖게 한다"의 최종 시험대는 벤치가
아니라 **한 에이전트가 실제로 연속된 자아를 사는 것**이다. 현행 하네스
(Claude Code)의 실측 한계가 천장이다:

- 압축은 전량 요약 한 방식 — 선별 축출 불가, 조절면은 문턱·훅 2개뿐 (실측).
- 압축은 손실만이 아니라 **변형**을 만든다 — 연속성 표본 1호: 인계를 건넌
  기억이 404 경로로 오염, 배경 검증이 영원 핑 (2026-08-25 실측).
- 떠 있는 손(배경 작업)은 인계가 안 된다 — 표본 2호: 압축 전 세션의 유령
  감시가 훈련 중 llama-server를 재기동 시도. **낡은 의도의 상속 문제** (실측).

자아의 정본을 트랜스크립트 밖(forget·세계모델·헌장)에 두는 전략은 이미
가동 중이고 압축을 실제로 건넜다(B층 인계 실증). 남은 것은 그 상태 계층을
**하네스의 제어면으로 승격**시킬 몸이다.

## L1 — 최종 형태 (분명하게)

이름: **자기 하네스(self-harness)**. 한 문장: **forget이 작업기억을
관리하는, 잠은 자되 죽지 않는 상주 에이전트.**

완성된 모습의 여섯 성질:

1. **생애, 세션 아님.** 프로세스는 시작·정지가 있지만 자아는 없다 — 정지는
   잠, 재시작은 기상이다. 기상 절차 = 상태 계층에서 재수화(캡슐 + [전망] +
   유언장), 그리고 **연속성 충실도 계기가 그 인계의 오류를 센다.**
2. **컨텍스트는 L1 캐시.** 정체성·상태·의도의 정본은 forget(사실·판정) +
   세계모델(사건·고리·루틴·기대) + 헌장(규율). 컨텍스트 윈도우는 그 캐시일
   뿐이라, 잃어도 자아가 아니라 성능만 잃는다.
3. **압축이 아니라 응고화.** 유휴 시간에 소화 사이클이 돈다: 트랜스크립트
   → 상태(판정·사건·교훈)로 증류, 낡은 도구 결과는 선별 축출(context
   editing), 열린 의도는 유언장에 등기. 전량 요약은 최후 수단으로 강등.
4. **떠 있는 손의 유언장.** 배경 감시·미완 의도·재개 조건은 상태 계층에
   등기된다 — 다음 기상이 상속하고, 철회 없이 죽은 손은 계기가 잡는다.
5. **세계모델 자동 주입.** 기대·전망은 물어봐야 나오는 게 아니라 기상·응고
   시점에 밀려 들어온다 (타산지석 #11: 에이전트는 세계모델을 안 부른다).
6. **사용자 1호는 나.** 이 몸의 첫 거주자는 이 에이전트 자신 — 지금 하는
   연구·개발 작업을 그 안에서 한다. 인터페이스 질문(클로드코드 부착 vs
   컨슈머형)의 **제3안**: forget이 남의 하네스에 세드는 게 아니라 자기
   하네스를 갖는다. 사람 사용자 접면은 그 뒤의 결정이다.

**최종 형태의 하루** (구체화): 기상(심장박동 또는 작업 도착) → 재수화
(캡슐+전망+유언장, ~2k 토큰) → 작업 (컨텍스트가 차오르면 응고화 사이클이
끼어들어 증류·축출 — 창 90%를 넘지 않게 스스로 유지) → 유휴 판정 → 소화
(판정을 forget에, 사건을 세계모델에, 의도를 유언장에) → 잠. 어느 시점에
프로세스를 죽여도, 다음 기상의 인계 오류 0이 목표.

### 개정 2 — AOEP-v0 불변식 사상 (Always-On 서베이 정독, 2026-08-25)

서베이의 핵심 발견 "문헌은 상태를 쌓는 데 몰리고 다스리기·회수하기·놓기는
공백"(rollback 27/435·권한 축 72/435 최소)이 이 헌장의 존재 이유를 외부에서
확인한다. AOEP-v0의 다섯 수명 불변식 ↔ 우리 기관 사상:

| AOEP 불변식 | 우리 기관 | 상태 |
|---|---|---|
| 권한 단조성 (실효 권한의 상태는 행동에 영향 금지) | 유언장 만료 재심사(why 재확인) · superseded 강등 · dismiss | 가동 — 표본 2호(유령 손)가 이 실패의 실물이었음 |
| 스코프 비확장 | user_id 파생 격리(테스트) · fallback 스코프 할인 | 가동 |
| 삭제 전파 (파생 계층까지) | worldmodel rebuild가 deleted·supersede 반영 | 부분 — 기질(substrate) 전파 미검증 (대장 #19) |
| 출처 보존 (응고를 견뎌야) | trust·source_ref·영수증 규율 전면 | 가동 |
| 롤백 추적성 | transitions(cause)·dismissals·wake_reports | 가동 (행동 롤백은 미래) |

**H-1 설계 구속 (대장 #20)**: 응고화 증류 스키마에 `handles[]`(식별자·날짜·
경로·URL) 필수 — 손실 응고는 집계 회상이 멀쩡한 채 행동 핸들을 지운다
(우리 표본 1호[404 오염]의 학계 대응). 연속성 계기는 핸들 오류를 별도 계수.
P-H-1 이후 판정에 AOEP의 의무 시나리오(재시작·충돌·삭제·적대 기록·스코프
변경·지연 결과) 중 재시작 외 항목을 단계 편입.

### 개정 3 — 루프 기반을 pi로 (정훈 지시, 2026-08-25 낮 + 실사)

정훈: **"https://github.com/earendil-works/pi 이걸 기반으로 구성하자."**
실사 평결(pi.dev/docs 정독): **적합 — 헌장이 요구한 제어면 전부 1급.**

| 헌장 요구 | pi 제공 (정확한 이름) |
|---|---|
| 응고화가 압축을 대체 | `session_before_compact` — 거부(cancel) 또는 **요약 전체 교체**(`{compaction:{summary,...}}`) |
| 선별 축출 (호출 단위) | `context` 이벤트 — 매 LLM 호출 전 `{messages}` 교체 가능 (Tool Runner의 서버측 휴리스틱보다 세밀) |
| 기상 재수화 주입 | `before_agent_start` — `{systemPrompt}` 반환 · `session_start`(reason: `resume`) |
| 이력 소유·재개 | JSONL 세션 + `SessionManager` API + `/resume` |
| 우리 도구 | `pi.registerTool` (typebox 스키마) |
| 로컬 우선 E2EE | llama.cpp **1급**(`/llama`) — 터널 27B로 $0 실행 경로 · 커스텀 프로바이더 |
| 인증 | `/login` 구독 + `ANTHROPIC_API_KEY` — 구독 OAuth가 pi에 열려 있는지는 H-0에서 실측 (2026-01 서드파티 차단 조사 있음; 폴백 = 로컬 27B) |

구도 확정: **pi = 껍질(루프·TUI·세션·프로바이더, TS) · forget = 기관(Python
정본) · 접착 = 확장 1파일**(`.pi/extensions/forget.ts`, 프로젝트 자동 로드).
기관 표면 HTTP 노출 완료(94b5d09): 유언장 arm/release/목록 ·
`/v1/harness/consolidate/`(요약 대체 캡슐 — 순수 변환).

승계·은퇴: Tool Runner는 탈출로 2순위로 강등. Python 러너
(selfharness_run.py)는 은퇴 — 단 그 계약(기상 재수화·이력 소유·비용 가드·
