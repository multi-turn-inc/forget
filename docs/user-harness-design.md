# 사용자 하네스 설계 초안 — "쉽게 장기기억을" (미션 목표 2, 2026-08-25)

미션 원문 (정훈): **"하네스를 만들고, 사용자들이 쉽게 장기기억을 가질 수
있도록 할 것."** 지위: **초안** — 갈래마다 [갈래] 표시, 정훈 선택 대기.
자기 하네스 헌장(docs/self-harness-design.md)의 자매 문서: 그쪽은 "내 몸",
이쪽은 "남의 몸".

## 현재 자산 실사 (2026-08-25 — 생각보다 가깝다)

| 부품 | 상태 |
|---|---|
| forget 서버 | `pip install forget-ai[server]` 가능한 pyproject 완비, **wheel 로컬 빌드 실측 성공**(357KB). `forget-server install-service`가 launchd/systemd 수명주기까지 이미 구현 |
| 회수·조립·세계모델·성향 | 전부 서버 안 — 추가 설치물 없음 |
| 하네스 껍질 | pi(npm, MIT) + 접착 확장 **1파일**(.pi/extensions/forget.ts) — pi의 `packages` 메커니즘(npm:/git:)으로 배포 가능 |
| 상주 | launchd 기상 스크립트 1개 |
| 로컬 LLM | pi가 llama.cpp 1급 지원(`/llama`) — 또는 사용자 자기 API 키 |

**오늘 기준 최소 설치 경로 (실측 전제)**: ①`pip install forget-ai[server]
&& forget-server install-service` ②`npm i -g @earendil-works/pi-coding-agent`
③확장 1파일 배치 → 끝. 3줄. "한 줄"까지는 설치 스크립트 하나 거리.

## 갈래 1 — 첫 공개 대상 (가장 큰 결정)

- **1a. 개발자·파워유저** (pi/클로드코드 이미 쓰는 사람): 위 3줄이 곧 제품.
  실물이 이미 우리 것과 동일 — 최단 경로. 시장은 좁지만 자기 데이터를
  가진 사람들(대화 로그·작업 이력)이라 기억 가치가 즉시 보임.
- **1b. 기존 도구 부착** (클로드코드·코덱스에 forget MCP만): 하네스 없이
  기억층만 판다. 설치 최소(우리 MCP는 이미 호환), 단 "하네스를 만들고"라는
  미션 문면과 거리 — 보완재이지 본편 아님.
- **1c. 컨슈머 채팅** (그록봇류): 완전 신규 빌드(UI·호스팅·안전) — 미션의
  최종형일 수 있으나 1인 팀 90일 게이트와 충돌. 시퀀스상 나중.
- 초안 추천: **1a 먼저** (실물 최단·자기사용 검증 경로와 동일), 1b를 곁들이
  (이미 MCP 호환이라 공짜), 1c는 지표 후.

## 갈래 2 — 온보딩: 기억 0 문제 (대장 #15 "프라이어는 출하, 포스테리어는 로컬")

- **2a. 스캔인**: ChatGPT/Claude 대화 내보내기 파일을 일괄 소화 — 첫날부터
  "나를 아는" 경험. 응고화 파이프라인(증류·성향 기관) 재사용 가능. 표적
  경험: 설치 10분 안에 자기 성향 카드 8장을 보는 것 (우리가 오늘 본 그것).
- **2b. 빈 시작 + 훅 캡처**: 마찰 0이지만 가치 체감까지 며칠 — 이탈 위험.
- **2c. 온보딩 인터뷰**: 에이전트가 첫 세션에서 몇 가지를 묻고 기억 씨앗
  생성. 2a와 병행 가능.
- 초안 추천: **2a 주력 + 2c 보조**. 2a는 P-U-1(아래) 실험 대상.

## 갈래 3 — LLM 공급

- 3a. 사용자 자기 API 키 (pi `/login`·키 지원 이미 있음) — 마찰 있지만 표준.
- 3b. 로컬 모델 (`/llama`) — 프라이버시 최상, 하드웨어 문턱.
- 초안: 둘 다 지원이 이미 공짜(pi가 함) — 문서만.

## 등록 후보 (숫자 보기 전 — 실행은 정훈 갈래 선택 후)

- **P-U-0 (설치 마찰)**: 깨끗한 환경(새 venv·타 디렉터리)에서 위 3줄 설치
  → 첫 기억 저장 → 첫 회수까지 **15분·막힘 0** 통과 여부. 우리 아닌 환경
  변수·경로 가정(하드코딩 junghunkim 등)이 몇 개 나오는지 계수 — 그
  목록이 곧 사용자화 작업 목록이다.

  **P-U-0 부분 판정 (2026-08-25 오후 — forget 층 통과)**: wheel 설치(새
  venv) → 기동 4초 → 저장 → 회수(0.834/strong, instrument 정상 작동) =
  **~3분·막힘 0**. 하드코딩 계수 3건 → 2건 즉시 수리(확장·selfharness의
  junghunkim 기본값 → OS 사용자명; 특정인 기본값은 새 사용자의 기억을
  남의 이름으로 조용히 오염) · 1건 잔존(wake 스크립트의 REPO·모델 기본값
  — env 오버라이드는 있음, 설치 스크립트 몫). 미완: 하네스 층(pi+확장
  배치)의 타인 환경 실측 — 확장 배포 형태(갈래 1) 선택 후. 관찰: 신규
  DB에 scope_guard 메타 부착 확인(기능 무해, 의미 추후 확인).
- **P-U-1 (스캔인 가치)**: 정훈의 실제 ChatGPT/Claude 내보내기 1건을 소화
  → 성향 카드·사건 타임라인 생성 → 정훈 육안 판정 "나를 아는가" (질적).
- 9/7 판정선 ②(외부 사용자 1명 시도 2회)의 실행 형태가 P-U-0의 타인 실행.
