## 처방 (표면별, 게이트 = 배포 전 정훈)

**forget.sh** — 기술적으론 건강(협상 설계 확인). 남은 건 시각 — 정훈이
타 세션에서 작업 중, 이 세션은 불개입. (오진 기록: curl 기본 UA로 재서
설치 스크립트를 «title 부재»로 읽음 — 측정 도구의 UA를 명기할 것.)

**multi-turn.ai (본론)** — 글 표면의 빈 집 채우기. 에세이 후보 3 (여름
자산의 공개 가능분, 초안은 내가):
1. «잘 잊는 것이 건강한 기억» — 할머니→이름의 기원→능동 망각의 뇌과학
   (Hardt: "망각 없이는 아무것도 작동하지 않는다")→forget의 침강 설계.
2. «벤치마크를 자신에게 겨누다» — 회상 실패 문제집(RECALL-BENCH)과 선등록
   규율. 수치 아닌 방법론 서사라 공개 안전.
3. «손-공식은 학습에 진다» — 감쇠 은행 이야기 (LME-V2 언급 없이 제품
   회상 개선 서사로).

**GitHub** — org 프로필 README 신설(멤버·표면 지도), homepage 레포
README, hebo1221/forget 포크에 "moved to multi-turn-inc/forget" 표지.
