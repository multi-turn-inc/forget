# RECALL-BENCH — 결정 시점 회상 하네스 (사고 은행 + 재생기)

2026-08-30 제정 (정훈: "이걸 해결 못하면 우리 제품 못내. 지금 만들고 있는
하네스에서 그걸 만들어볼까?"). 우리 벤치 규율(선등록·소음 바닥·안정 표적)을
**자사 회상층의 실전 실패**에 겨눈다. 실물: research/recallbench/
(incidents.jsonl + replay.py).

## 원칙 — 전부 오늘 밤 측정 버그가 하나씩 가르친 것

1. **실전 사고만 입행** (합성 금지) — 사고가 표본을 정한다.
2. **원문 충실** — 질의를 정제해 저장하면 재생이 거짓 통과한다
   (inc-004 1차: ssh 명령줄을 지운 은행이 PASS를 조작).
3. **채널 충실** — 사고가 난 채널(훅/상황 좌석/검색)로 재생한다
   (v0 재생기가 훅 사고를 검색으로 재 오판 2건).
4. **세션 상태 충실** — 반복 억제 원장·대화 꼬리 등 세션 상태를 시딩해야
   장수-세션 병이 재현된다 (inc-004 3차: 신선 세션 재생이 거짓 통과).
5. **측정이 제 씨앗을 읽지 않게** — 시딩분은 판정에서 제외.

## P-R-1 등록 (숫자 보기 전 고정) — 억제 TTL·고점수 재부상

- 가설: 반복 억제는 소음 방지 기관이지만 무TTL이라 장수 세션 후반의 회상을
  질식시킨다. 수리: 턴-주입 억제에 TTL(제안 후 N턴 경과 시 재제안 허용,
  N=40) + green 결정/정책 기억은 고점수(문턱+0.05) 시 TTL 무관 1회 재부상.
- 예측: 은행 inc-004 PASS 전환 · inc-001~003 판정 불변 · 오발률(게이트
  원장 주입/턴 비율) 악화 +20% 이내.
- 판정: 셋 다 충족 → 채택. 오발률 +20% 초과 → N 상향 재등록 1회 후 재판정.

## P-R-2 등록 (숫자 보기 전 고정) — 상황 판독기 기권 강화

- 수리: 판독기 프롬프트에 «질문이 어떤 트랙의 상태도 필요로 하지 않으면
  반드시 none» 명시 + ETA/시간/인사류 결정론 선차단.
- 예측: inc-003 PASS 전환 · inc-001 불변(표본 질의 트랙 적중 유지) ·
  §19 수제 10질의 재실행에서 상황 적중 ≥4/5 유지.
- 판정: 셋 다 충족 → 채택.

## 운용

- 새 사고 = 즉시 입행 (원문·채널·세션 상태 동봉) — 수리 전 FAIL 상태로.
- 수리 팔은 선등록 후 구현, 채택 조건 = 표적 PASS + 기존 PASS 전원 유지.
- 재생은 배포 전 회귀 스위트로 상시 실행 후보 (야간 편입 검토).

## MUS — 기억 유용성 점수 (v0 정의, 2026-08-30 정훈 북극성 지정)

정의: **MUS = mean(bank, situation, outcome)**, 각 [0,1] —
- bank: 사고 은행 재생 통과율 (문제 해결의 자)
- situation: 상황 좌석 정밀도 ((적중+무관침묵)/10질의)
- outcome: 30일 context_outcomes의 helped 비율 (실사용의 자)
산출: research/recallbench/score.py → 스냅샷은 series=recallbench.mus 기억
(시계열 승계가 정본 유지 — 자기 기관의 도그푸드).

**첫 스냅샷 (2026-08-30): MUS 0.562** — bank 0.75 · situation 0.90 ·
outcome 0.036. outcome 축 주의: 자동 라벨러의 가혹 판정이 지배하는 수치로
보임(수동 helped 호출은 소수) — v0.1에서 라벨 원천 감사 후 재정의 등록.
점수는 정의 개정 시 시리즈를 갈라 비교 불가를 명시한다.

## P-V-1 등록 (2026-08-30, 숫자 보기 전 고정) — 구조 자체의 타당성 판정

이 하네스가 옳다는 확신은 내부 지표가 아니라 **도구 밖 변수의 예측**에서만
온다. 목적 변수 = **정훈의 정정 빈도** (실전 대화에서 회상 실패를 사람이
잡아줘야 하는 횟수 — 신규 사고 입행 수가 그 계기).

- 기준선: 2026-08-29~30 하루 동안 실전 사고 4건 (역대 최고 밀도 —
  단 관측 강도도 최고였음을 병기).
- 예측: 은행·MUS 개선이 진짜라면 **4주 창(~9/27)에서 주당 신규 실전 사고
  수가 하강 추세** — 특히 기존 유형(상황·시계열·억제·오발)의 재발 0.
- 판정: 기존 유형 재발 ≥2 → 수리가 가짜(회귀 가드 실패), 구조 재설계.
  신규 유형만 계속 등장 + 주당 수 비하강 → 은행이 분포에 수렴 못 하는 것
  — 표본 수집 채널 재설계(수동 정정 의존 탈피). 하강 + 재발 0 → 구조 지지.
- 부기: 관측 강도 교란(정훈이 덜 보면 사고가 덜 잡힘) — 사고 밀도는
  대화 시간당으로 정규화해 기록한다.

**굿하트 방어 3선 (상시)**: ①표본은 실전만 — 내가 공급 불가 ②판정선은
등록 시 고정, 개정은 결과 열람 전만 ③점수 정의 변경 = 시리즈 분리.
