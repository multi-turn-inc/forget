# 기억 지능 헌장 — 사다리 컴파일러

2026-08-29 제정 (정훈·클로드 이틀 논의의 응고). 모토가 정본:
"명시적 기억은 미래에 대한 정보를 제공하기 위해 존재한다. … 호랑이 줄무늬
개수를 잊어도 번식에 실패하지 않지만, 그 만남으로 다시 만나는 가상의 모델을
못 만들면 실패한다."

## 1. 왜 이전 실험들이 실패했는가 (실패 장부 4층 + 법칙 3)

층1 개별 사인(더듬기 남발·ABS 환각·GROUND 소음·B2 무익·카드 무익·GRPO 무학습)
→ 층2 지시문으로 기관 흉내 → 층3 **얼어 있는 피질의 입력 언어**: 성공 개입
전부 "모델이 이미 소비하는 언어(관련 구절)를 더 잘 골라주기", 실패 전부
"새 장르 발명해 먹이기"(목록·카드·노트·메타지시) → 층4 **사다리 건너뜀**:
성공한 장기기억(CLAUDE.md 규약·eval 가드)은 전부 일화→반복→검증→증류를
거쳤고, 실패한 팔은 가설→컴파일 직행.

- **법칙 A "힌트도 예산"** (3회 실측): 옳은 정보도 어텐션 예산을 점유하며
  기본값이 마이너스다.
- **법칙 B "뺄셈이 이기고 덧셈이 진다"**: 큰 승리 전부 제거·축소·절제.
  덧셈 예외 셋(premise·RECOMMEND·언어화)은 모두 기존 행동의 방아쇠.
- **법칙 C "계기가 가설보다 먼저 죽는다"**: 실패 절반이 측정의 죽음.
  선등록·짝지음·저지 분리·소음 바닥이 두 달의 진짜 산출물.

## 2. 라벨 회의론 (정훈 경고의 성문화)

- 에코는 사용이 아니다(주입이 에코를 낳는 순환·억제 기억은 흔적 없음 —
  에코 라벨 최적화 = 굿하트).
- 반사실은 관찰로 안 나온다 — 개입(ε-보류)이 유일한 인과 라벨.
- 시간 근접 신용은 우리 규모(수천 턴)에서 미신을 배운다.
- 정직한 라벨 3원: **ε-보류(개입) · 행동-결합(세계가 채점) ·
  어텐션 라벨(자가 호스팅, P-A 부검의 "예측기가 아니라 라벨러")** —
  서로 다른 편향의 교차 검증. 약한 라벨은 장기-부재 강등에만.

## 3. 인간이 싼 이유 — 컴파일 사다리 (지속학습의 답)

일화 제어(습득 0·실행 비쌈) ↔ 습관(습득 비쌈·실행 0)의 교환.
LLM의 일화 제어 = 인컨텍스트 학습 — **1단은 이미 있다.**

| 단 | 매체 | 우리 실물 |
|---|---|---|
| 1 일화 | 기억 행 → 컨텍스트 | forget 원장 ✓ |
| 2 규칙 | 상시 로드 문면 | CLAUDE.md·기상 프롬프트 ✓(수동) |
| 3 절차 | 스크립트·가드·스킬 | eval 가드·wake.sh ✓(수동) |
| 4 가중치 | LoRA (자기 검증 일화의 행동 복제) | 미구축 — 최후 단 |

승급 결정식: `사용 빈도 × 단당 비용(토큰·소음) > 컴파일 1회 비용`.
지속학습이 공짜로 풀리는 이유: 새로움은 1단에 흡수, 가중치엔 변화가 멈춘
패턴만 — 간섭 없음. 훈련 비용이 업무 비용 안에 접힌다(연습=수행).
SFT/GRPO 판정: 프레임으로는 죽고(오프라인·외부 라벨·긴 지평), 도구로는
4단에서만 — 자기 검증 일화의 극소 행동 복제.

## 4. 컴파일러 — 응고 심장의 승격

임무: **반복을 감지해 알맞은 형태로 증류하고 원본을 강등한다.**
(두 달간 손으로 해온 것의 자동화 — 대체 대상이 실존하는 과제.)

### 4.1 실DB 실측 (2026-08-29, 군집 탐사)

7,334 벡터(768d) 중 **68%(4,987행)가 반복 군집**(sim>0.80, ≥4회) 안:
- 세션 캡처 포인터 2,893행 (인프라 — 지식 아님)
- devloop 저널 계열 556+ (보존 영토)
- **이미 컴파일된 규칙의 일화 재축적**: 시각 비교 규율 120회/4일 —
  기상 프롬프트에 박힌 문면이 매 기상 재저장되는 병리
- 같은 사실의 재진술: 63회("이슈 등재 확인") 등
- 헤비안 카운터는 비어 있음(evidence_count 보유 3행) — 반복은 근사-중복이
  아니라 **날마다 다른 표현**으로 온다 → 감지는 임베딩 군집이 정본.

### 4.2 v0 파이프라인 (결정론 후보 + LLM 게이트 — P-PF-2 교훈)

```
[감지 — 결정론] 다일(≥3일) 임베딩 군집 (sim>0.80, ≥4회)
[분류 — 결정론 1차 + 로컬 LLM 게이트]
  capture-pointer → 컴파일 제외 (인프라 정리는 별도)
  journal(devloop 등 타 트랙) → 불가침
  rule → 정본 1행 승격 + "이미 컴파일됨" 링크 (기상 프롬프트·CLAUDE.md 대조)
  fact → 정본 1행 병합 (evidence_count = 군집 크기, 최신 표현 채택)
  procedure 후보 → 사람 게이트 제안서 (코드 자동 생성 금지)
[집행] 정본 승격 + 나머지 supersede 링크 강등 (기존 침강 파이프라인 재사용,
       가역 · 삭제 아님) — 원장 위 회상 경쟁에서 4,000+ 중복이 빠진다
```

법칙 B의 원장 적용: 컴파일의 1차 효과는 **뺄셈**(회상 후보 노이즈 제거)이고,
증류물(정본·규칙)은 그 부산물이다.

### 4.3 P-C-1 선등록 (숫자 보기 전 고정)

  상태의 반복 저장 — 올바른 컴파일은 "최신만 정본, 구본 supersede"
  (fact-병합의 시변 특수형). 게이트 어휘에 없어서 other로 갔다.
- 최대 강등 질량은 설계상 컴파일 제외였던 캡처 포인터(2,928행) — 회상 경쟁
  소음의 주범이며 별도 위생 레인(재수화 포인터는 회상 후보에서 구조적 제외)

  순수 개인 층 분모에서 도피 5건이 그대로 드러남.
- **오류의 모양이 하나다**: 명백한 rule·현재형 계기(PID·사이클 번호)는 잡고,
  **관측-보고형 시변 진술**("reveals"·"is contaminated"·"does not exist")을
  전부 other로 보낸다. 어휘 2라운드 소진 — 등록 분기대로 **27B 한계 확정**.

### 4.10 P-C-1d 등록 (숫자 보기 전 고정) — 게이트 모델 승급
