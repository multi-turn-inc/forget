# 유한 기억과 컨티뉴얼 러닝 — CLS 아키텍처

2026-08-23. 정훈의 비판에서 출발한다: "장부를 열심히 쓰는 건, 프롬프팅으로 간단하게
구현하는 건 뇌를 너무 나이브하게 보는 것 같아. 기억의 한도를 정해놓고, 망각이
지능적으로 들어가야 해. 컨티뉴얼 러닝."

이 문서는 [episodic-binding.md](episodic-binding.md)(쓰기 경로 수리)를 포함하는
상위 아키텍처다. 기준 결정은 2026-08-12의 배분이다:
**사실은 컨텍스트로 · 습관은 가중치로 · 장부는 훈련 신호로.**

## 철학: 한도가 지능을 강제한다

무한 append는 기억이 아니라 기록이다. 버릴 것을 결정할 필요가 없는 시스템은
무엇이 중요한지 이해할 필요도 없다 — 망각 없는 저장소에는 취향이 생기지 않는다.
뇌의 제약(대사 예산, 시냅스 수)이 지능적 압축을 강제했듯, 이 시스템도 유한해야
지능이 강제된다.

단, 감사(audit)와 기억(living store)은 다른 기관이다. 컴플라이언스 제품 서사가
요구하는 "무엇이 있었고 왜 잊었는가"는 영구히 남고, 살아있는 기억은 유한하다.
**잊되, 잊었다는 사실은 잊지 않는다** — 게이트 로그의 원칙을 망각까지 확장한다.

## 사층 사다리 (한도는 명시적 손잡이)

| 층 | 이름 | 한도 | 내용 | 현존 여부 |
|---|---|---|---|---|
| L0 | 상주 (hot) | **40** | 캡슐 — 항상 컨텍스트에 | 있음 (decay-LFU + 최신석 + 현직 보너스) |
| L1 | 활성 (warm) | **10,000 (하드 캡)** | 검색 가능한 살아있는 기억 | 지금의 memories 테이블 (현재 7,292 — 곧 압박 시작) |
| L2 | 냉장 (cold) | 무제한 | 기본 검색 제외, event_id/hash 정확 참조로만 복원 | 신설 (deleted 플래그의 일반화) |
| L3 | 감사 (audit) | 무제한·불변 | hash·출처·supersede 체인·**망각 기록** (텍스트 없음) | 게이트 로그의 확장 |

"삭제가 아니라 비상주"(하나의 잊음 원칙)의 완성형: L1→L2는 접근성 강등이지
소멸이 아니고, L2→소멸조차 L3에 흔적(무엇을·언제·왜)을 남긴다.

## 지능적 망각 — 세 기전

### 1. 헤비안 병합 (쓰기 시점)

새 기억이 기존 기억의 근사중복(3그램 자카드, 읽기 경로에 이미 있는 그 기준)이면
**append하지 않는다**. 기존 항목을 강화한다: `evidence_count += 1`, recency 갱신,
출처가 더 강하면(green>yellow) 출처 승격. 반복은 사본이 아니라 강도가 된다.
— 오늘 아침 실측된 "같은 기억 2개가 회상 5칸 중 4칸 차지"의 근본 수리이며,
읽기 경로 중복제거는 이후 안전망으로 강등된다.

### 2. 다신호 강등 압력 (L1 캡 도달 시)

강등 점수 = f(효용, 출처, 상태, 나이, 응고 여부):
- **효용**: 회상 이력 + helped/noise 피드백 (어제 배선한 그 신호 — 여기서 배당)
- **출처**: red(폐기) 최우선 강등, 미검증 action_report 다음, green 최후
- **상태**: superseded는 즉시 강등 후보 (원장 계약상 회수는 L3가 보장)
- **응고 여부**: 아래 자격시험 통과분은 안전 강등

압력은 캡에서만 발동한다 — 캡 아래에서는 아무것도 강등하지 않는다 (여유가 있는데
버리는 것은 지능이 아니라 낭비다).

### 3. 망각 자격시험 (기계적 정의 — 단, 적용 범위가 갈린다)

> **배운 것만 잊는다.**

강등 후보에 대해: 그 기억을 컨텍스트에 넣지 **않고**, 응고 산물(요지 항목 또는
어댑터)만으로 그 기억의 프로브에 답하게 한다. 정답이면 응고 확인 → 안전 강등
(L3에 "응고 확인 후 망각" 기록), 오답이면 잔류.

**적용 범위 교정 (2026-08-23, 정훈의 "QLoRA가 맞아?" 질문이 드러낸 모순 수리):**
초안은 이 시험을 모든 기억에 걸었는데, 사실(fact)은 가중치 금지 원칙 때문에
영원히 불통과 — 강등 문이 안 열리는 자기모순이었다.
- **사실 기억**: 시험 대상 아님. 효용·중복·폐기 신호만으로 강등한다 (그게 정직한
  기준이다). MTT(다중흔적이론)와도 정합 — 일화의 세부는 평생 해마 의존이다.
- **요지·습관**: 시험 대상. 응고 산물(증류된 요지 항목, 행동 어댑터)이 원본 없이
  프로브를 통과할 때만 원본 조각들을 강등한다.

## 컨티뉴얼 러닝 — 수면 루프

### 응고 대상 삼분 (2026-08-23 교정: "가중치"는 생성기 가중치가 아니다)

정훈의 질문("그 부분을 QLoRA로 해결하는 게 맞아?")이 초안의 오배치를 드러냈다.
QLoRA-on-생성기는 실측 병목(의역 검색 실패)을 하나도 건드리지 못하고, 승인 21쌍
으로는 SFT가 과적합 암기가 되며, 매 턴 모이는 신호(helped/noise)는 생성 신호가
아니라 **랭킹 신호**다. 응고 대상을 셋으로 가른다:

1. **리트리버/리랭커 가중치 (1순위 — 진짜 첫 컨티뉴얼 러닝 런)**
   - 훈련: (질의, 도움된 기억)=양성 / (질의, 무시된 기억)=음성의 대조학습.
   - 데이터가 이미 흐른다: context_traces의 selected_ids(수개월치) + 피드백 루프
     (어제 배선 — 매 턴 쌍을 생산). 이것이 "장부는 훈련 신호로"의 실체.
   - bge-small급(수십M 파라미터)이라 4090에서 분 단위, 맥에서도 가능.
   - **리트리버는 환각을 못 한다** — 순위만 매기므로, 기억 제품의 학습으로 안전.
   - 뇌 정합: 해마 재생이 가르치는 것은 사실의 재생산이 아니라 *찾는 능력*이다.
2. **요지 응고 = 텍스트 증류 (2순위)**
   - 수면 때 같은 주제 조각들을 요지(gist) 항목으로 증류해 L1에 승격, 원본 조각은
     출처 링크를 단 채 강등 후보로. 피질 스키마의 등가물을 가중치가 아니라
     **원장 안의 상위 항목**으로 만든다 — 감사 가능하고 되돌릴 수 있다.
3. **생성기 QLoRA (3순위, 하나의 인격 전용)**
   - 대상: 반말 규율, 병리(반향·되새김질) 억제, 정체성 안정 — 행동은 가중치 감이
     맞다(프롬프트 준수가 확률적임을 밤새 실측). 단 이것은 하나의 몸을 위한 것이지
     기억 제품의 회상 경로가 아니다. 4090, 나중.

**절대 가중치 금지 유지**: 정확 수치·고유명사·일정·일회성 사실. 가중치는 사실을
환각한다. 사실의 생애주기는 위의 망각 기전(효용·중복·폐기)이 관리한다.

### 루프 (밤마다 또는 유휴 시)

```
채굴(랭킹 쌍) → 리트리버 대조학습 → 평가 게이트 → 승격 → 요지 증류 → 자격시험 → 강등
```

- **평가 게이트** (`get_model_adapter_promotion_report` 현존): 개인 평가셋에서
  구모델 대비 회상 개선 + 문면 질의 1위 유지(후퇴 금지) + LME-V2 mini 무후퇴.
- 승인 파이프라인 현존 (승인 21쌍, 2026-08-13) — 랭킹 쌍 채굴로 확장.

## 사전 등록 판정 기준

1. **어댑터 효과**: on/off A/B에서 개인 평가셋 유의 개선 + LME-V2 mini 무후퇴.
2. **압축 내성 (지능적 망각의 최종 시험)**: L1을 절반(5,000)으로 강제 압축해도
   평가셋 회상이 유지되는가. 대조군 = 무작위 강등. 지능적 강등이 무작위보다
   유의하게 좋아야 한다 — 아니면 "지능적"이라는 말을 쓸 자격이 없다.
3. n=8 잡음 교훈 유지: 판정선은 2문항 이상의 차이를 요구한다.

## 구현 순서 (의존성 순)

1. 헤비안 병합 — 게이트 불요(신규 쓰기만), 즉시 효과, 오늘 아침 결함의 근본 수리
2. 랭킹 쌍 채굴기 — context_traces + 피드백에서 (질의, 양성, 음성) 추출, 게이트 불요(읽기)
3. 리트리버 대조학습 첫 런 + 평가 게이트 — 훈련 자체는 무해, **승격(임베딩 교체+재색인)은 게이트**
4. L1 캡 + 다신호 강등 + L2/L3 — 강등 실행은 실DB 변경이라 **게이트**
5. 요지 증류 + 자격시험 — 2·3이 있어야 의미
6. 압축 내성 시험 — 전체의 최종 검증
7. (나중) 하나 인격 QLoRA — 기억 제품이 아니라 하나의 몸 트랙

## 위험과 방어

- **파국적 망각**: LoRA(동결 베이스) + 리허설 리플레이 + 게이트의 무후퇴 조항.
- **사실을 가중치에 넣는 유혹**: 채굴 단계에서 사실형(수치·고유명사·날짜 포함)
  훈련쌍을 기계적으로 배제. 이 선을 넘으면 환각이 "기억"의 탈을 쓴다.
- **자격시험의 위양성** (우연히 맞혀서 잊음): 프로브 3문 중 3정답 요구 + 강등이지
  소멸이 아님(L2에서 복원 가능)이 안전판.
- **평가 없는 승격**: 게이트 API가 이미 막고 있음 — 우회 금지를 명문화.
