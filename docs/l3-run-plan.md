# L3 런 계획 — 리더 상향 공표 런 (게이트 대기, 발사 준비 완료 상태)

지위: **준비 완료·발사 게이트 대기.** 예산 근거: 2026-07-26 정훈 승인
$1000 (3-seed 재실행·로컬 리더 런·BEAM 용도). 이 런(새 더듬기 하네스 +
GPT-4o 리더)은 그 문면의 직계 연장이나 명시 용도 밖이므로 **발사 전 정훈
한 마디 확인** — "L3 발사"면 즉시 실행.

## 왜 (근거 사슬)

- L2 종결 판정: 0층 프롬프트 수확 종료, G 0.730이 로컬 27B 리더의 상한.
- preference 시리즈(P-PF-1~5): 잔여 실패가 일관되게 **리더 역량**(제안
  의지·배타성 준수) — 컨텍스트·지시·카드로 불가 실증.
- L1 실측: 검색 도달은 만점(바늘@84 = 1.00) — 격차는 전부 하류(리더).
- 경쟁 좌표: Evermind 83.0 공표 중 (하네스 달라 직접 비교 불가 명기).

## 무엇을 (등록선은 발사 승인 후 별도 고정)

- 구성: 팔 G (+ P 추천 탐침 — preference 커버) 그대로, 리더·저지만 상향.
- 표본: n=100 정본 목록 (L1·L2와 동일 — 사과 대 사과).
- 리더 후보: GPT-4o (기존 공표 런과 동일 저지 계보) 또는 GPT-5 계열
  (최신 좌표) — 발사 시 정훈 선택, 기본 추천 GPT-4o(비교 가능성).
- 저지: 공식 JUDGE_TEMPLATES 문면 그대로 (하네스 내장).

## 어떻게 (1커맨드 — 기술 준비 완료)

```bash
MEM1_DB_PATH=<벤치DB> \
LME_LLM_URL=https://api.openai.com/v1/chat/completions \
LME_LLM_MODEL=gpt-4o LME_LLM_API_KEY=$OPENAI_API_KEY \
LME_L2_OUT=research/eval/lme_L3_G_rows.jsonl \
.venv/bin/python scripts/lme_l2_ab.py --n 100 --arms G
```

- 스크립트 패치 완료 (LME_LLM_MODEL·LME_LLM_API_KEY env — 로컬 기본 불변,
  스모크 통과). OPENAI_API_KEY는 환경에 존재 확인됨.

## 비용 추정 (2026-08-25 갱신)

G 평균 누적 ~11.8k tok/문항 × 100문항 ≈ 1.2M input + ~0.1M output.
GPT-4o ($2.5/M in · $10/M out): **런당 ~$4-6** (저지 포함 ~$5-8).
구 견적 $15-40보다 낮음 — 더듬기가 덤프(17.3k)보다 싼 덕.

## 공표 규율 (GTM 불변)

이긴 숫자만 공개 표면에. 하네스 상이 비교(공식 리더보드 대비)는 각주
의무. PM-Bench 숫자는 라이선스 미확정으로 공표 금지 유지.
