# 타산지석 대장 — 남이 이미 잰 실패, 우리의 선제 규칙 (2026-08-24 제정)

정훈: "다른 연구에서 삽질했던 것, 교훈을 우리가 빨리 받아들여야지. 같은
삽질할 필요는 없잖아." — 원칙: **측정된 실패만** 싣는다 (의견·직감 제외).
새 실험·기능 설계 전에 이 대장을 훑는 것이 절차다. 상태 열이 정직성의 핵:
"위반 위험!"은 지금 우리가 그 삽을 들고 있다는 뜻이다.

## 위반 위험 3건의 처방 (즉시)

- **#1**: P-W-1 판정에 "형식/문체 승리 vs 내용 선별 승리" 해부 의무 + P-W-2
  (사실-집합 GRPO)를 공식 후계로 등록.
- **#2**: 내부 LLM 판정 신설 시 배치 비교를 기본형으로 (공식 벤치 재현은 예외
  — 비교 가능성 우선).
- **#14**: 교재 확장 논의 전에 P-W-1 데이터 절제(1k/2k/3.1k 학습 곡선)를 먼저.

절차 편입: 새 P-등록을 쓰기 전에 이 대장과 대조하고, 위반 위험이 있으면
등록문에 해당 # 을 인용한다. 새 삽질을 발견하면(우리 것이든 남의 것이든)
행을 추가한다 — 대장은 자란다.
