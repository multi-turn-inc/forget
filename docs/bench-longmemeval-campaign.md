# P-B-1 — LongMemEval(v1) 캠페인 헌장

2026-08-30 발사 (정훈: "자랑할만한 수치를 만들어내보자. 필요하면 H100 한대").
LME-V2 트랙(제출 대기, LAFS +2.577)과 별개의 **대화형 장기기억** 전선.

## 전략 (자랑의 형태를 먼저 고정)

숫자 단독이 아니라 **신뢰 가능한 숫자**가 무기다 — 지형 실측(2026-08-29):
Mem0 94.4는 하드코딩 의혹, Zep 75.14 반박전, 리더보드는 토큰 예산 무병기.
우리의 공개 형태: ①같은 리더·같은 저지·같은 토큰 예산의 통제 비교
(full-context / naive-RAG / forget) ②재현 하네스 통째 공개 ③선등록 규율
(이 문서가 그 증거). 공개는 이겼을 때만 (GTM 규율).

## 벤치 선택

- 주전장: **LongMemEval-S** (500문항, 5능력 — IE·다중세션·시간·지식갱신·기권).
  우리 기관과의 사상: 지식갱신↔supersede+억제간선+재부상 · 시간↔reference_date
  · 교란↔Hebbian 병합+에코 차단 · 기권↔폐쇄 세계 진술(§5 공백 — 캠페인이
  다음 기관의 과녁을 정함).
- 보조: LoCoMo는 substring-F1 비판이 있어 2차 (돌려도 각주와 함께).

## 설계 결정 (숫자 보기 전 고정)

1. **적재**: 세션 스트림을 시간순 재생 — 세션당 forget add(infer=로컬 추출)
   + 타임스탬프 보존. 적재도 하네스의 일부로 공개.
2. **회상**: forget 제품 경로 그대로 (search_memories, 기어는 phase 1에서
   고정) — 벤치 전용 특수 경로 금지 (P-M-3 교훈: 벤치용 조작은 안 판다).
3. **리더**: H100 + vLLM의 오픈 모델 1개 고정 (후보: Qwen3.5-72B급 —
   phase 1에서 확정·병기). 전 팔 동일 리더 강제.
4. **저지**: 원 논문 프로토콜(모델 저지) + 저지 모델·프롬프트 고정 공개.
   개발 루프는 로컬 27B 저지, 최종 런만 고정 저지.
5. **토큰 예산 병기**: 팔마다 질의당 컨텍스트 토큰 중앙값을 결과와 같은
   표에 인쇄 — "92 @ 7k ≠ 92 @ 70k" 교란의 정면 돌파.

## 단계

- **0 (로컬, $0)**: 데이터 획득 → 적재 어댑터 → 3문항 배관 스모크.
- **1 (등록)**: 스모크 후 숫자 보기 전 예측 고정 — 전체 정확도 목표,
  이길 부분집합(지식갱신·시간) 명시, 팔별 토큰 예산 상한.
- **2 (H100)**: 리더 서빙 확정 → 500문항 × 3팔 → 저지 → 판정.
- **3 (게이트)**: 이기면 공개(하네스 포함) — 정훈 게이트. 지면 부검 후
  기관 개선으로 환류 (이번 여름 루프 그대로).
