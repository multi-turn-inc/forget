# 신경 기억 게이트 — 원문 정독과 융합 설계 (goal:neural-memory-gate)

2026-08-29. 발단: 정훈 "깊게 공부하고 고민해봐, 얕게 해결하려 하지 말고."
원문 정독: Titans(2501.00663)·TTT(2407.04620)·EM-LLM(2407.09450).

## 1. 수식 재서술 (성공 기준 ①)

### TTT — hidden state가 곧 모델

시퀀스 레이어 = (hidden state, update rule, output rule). TTT의 수:
hidden state를 작은 모델 f의 가중치 W로 둔다.

- 갱신: `W_t = W_{t−1} − η ∇ℓ(W_{t−1}; x_t)` — 자기지도 1 스텝
- 출력: `z_t = f(θ_Q x_t; W_t)`
- 손실(학습된 태스크): `ℓ(W; x_t) = ‖f(θ_K x_t; W) − θ_V x_t‖²`
  - **θ_V가 "무엇을 기억할 가치가 있는가"를 인코딩** — "not all information
    is worth remembering"의 해법이 라벨 뷰의 학습.
  - θ_K·θ_V·θ_Q·W₀·η 전부 **outer loop**(대규모 next-token prediction)에서
    meta-learning(gradient-of-gradient)으로 학습.
- 동치정리: linear f + batch GD = linear attention (Thm 1),
  Nadaraya-Watson = self-attention (Thm 2).
- 병렬화: mini-batch GD(b=16, `G_t = ∇ℓ(W_{t′}; x_t)`, t′=배치 경계) + dual
  form (`W_b = W₀ − 2η(W₀X−X)Xᵀ`).

### Titans — TTT + momentum + 망각 게이트

- 연상 손실: `ℓ(M_{t−1}; x_t) = ‖M_{t−1}(k_t) − v_t‖²`, k=xW_K, v=xW_V
- 놀람 분해: `S_t = η_t S_{t−1} − θ_t ∇ℓ(M_{t−1}; x_t)`
  (과거 놀람의 모멘텀 + 순간 놀람 — "큰 놀람 직후의 저놀람 정보 놓침" 수리)
- 갱신: `M_t = (1 − α_t) M_{t−1} + S_t` — α_t = 데이터 의존 망각(weight decay
  일반화, Mamba2 게이팅의 일반형)
- **α_t·η_t·θ_t를 산출하는 함수와 W_K·W_V·W_Q 전부 outer loop 사전학습.**
- M은 MLP L≥2가 유효(깊은 기억). 회수는 갱신 없는 `y = M*(q)`.

### EM-LLM — training-free, 서프라이절은 분절에만

- 경계 판정: `−log P(x_t|x_{<t}) > μ_{t−τ:t} + γσ_{t−τ:t}` (이동 창 적응 문턱)
- 경계 정련: 어텐션 key 유사도 그래프 `A_{ij}=K_i·K_j` 위 모듈러리티 최대화
- 회수 2단: similarity buffer(k-NN) + **contiguity buffer**(회수된 이벤트의
  시간 이웃 ±n을 동반 — 인간 자유회상의 시간 인접 효과 재현, k_c ≤ k_s 최적)
- **아무것도 훈련하지 않음. 그리고 서프라이절을 가치 판단에 쓰지 않는다 —
  전부 보관하고 경계만 긋는다.**

## 2. 지형의 재편 — 그리고 P-E-1 사인의 이론적 확정

| 단 | 서프라이절의 용도 | 가치 판단의 출처 | 검증 |
|---|---|---|---|
| EM-LLM | **분절** (경계) | 없음 — 전부 보관 | ✓ |
| TTT/Titans | 학습 신호 (gradient) | **outer loop 사전학습** (θ_V·게이트) | ✓ |
| P-E-1 (우리) | **가치 판단** (training-free) | — | **✗ 실측 기각** |

우리는 두 검증된 사용법 사이의 미검증 지대에 있었다. EM-LLM이 서프라이절을
가치로 안 쓴 것은 우연이 아니다 — **동결 모델의 놀람은 "예상 밖"만 알지
"값짐"을 모른다.** 값짐은 태스크가 정의하고, 이 계열에서 태스크는 θ_V·게이트
= outer loop의 산물이다. 우리에겐 그 사전학습이 없다. P-E-1은 이론적으로도
죽을 자리였다.

## 3. 이식 난점 (성공 기준 ②)

1. **outer loop 부재** — θ_V·α·η·θ를 배울 대규모 태스크가 없다.
   이벤트 7천 건으로 meta-learning은 과적합 확정(TTT도 from-scratch 장문
   훈련 불안정 보고).
2. **데이터 규모·비정상성** — 언어 토큰은 정상 통계·수십억 규모, 우리
   이벤트 스트림은 수천 규모에 프로젝트 피봇으로 분포가 이동. b=16
   mini-batch·모멘텀 시간상수가 유효한 체제가 다르다.
3. **부산물 사용의 미검증** — 우리는 M의 출력(z_t)이 아니라 학습 역학의
   부산물(loss·gradient norm·은닉 상태)을 게이트·프리페치로 쓰려 한다.
   이 계열 어느 논문도 검증 안 한 사용법 — 우리가 직접 실측해야 한다.
4. **α(망각) 학습 불가** — 데이터 의존 망각 게이트는 사전학습 산물.
   고정 상수 + 결정론 보완(놀람 지속 급증 시 리셋 = NE 아날로그)로 대체
   해야 하며, 이는 Titans 대비 명백한 열화다 (정직 부기).
5. **평가 계기 부재** — perplexity의 대응물을 새로 세워야: 다음-회수 예측
   recall@k (오프라인 리플레이, 기준선 = 현행 유사도 훅).

## 4. 돌파구 — 태스크를 바꾸면 outer loop가 필요 없다 (설계 결정 ①의 근거)

TTT가 θ_V를 학습해야 하는 이유는 **inner 태스크(재구성)와 실제 목적(NTP)의
괴리** 때문이다. 우리의 목적은 "다음에 필요할 기억의 예측"이고 — 이것을
**inner 태스크 그 자체로 삼으면 괴리가 0이 된다**:

> `ℓ(W; u_t) = ‖f(h_t; W) − u_{t+1}‖²`
> u_t = t번째로 **실제 사용된** 기억의 임베딩 (사용 로그가 시퀀스),
> h_t = 최근 사용 이력의 표현. f = TTT-Linear/MLP (residual+LN 포함).

- 라벨은 자기 생성(회수 로그) — 라벨 회의론의 세 함정(에코 순환·반사실·
  근접 신용) 중 에코 순환만 남는데, 이는 ε-보류로 보정 (기존 결론 유지).
- f의 출력 = 다음 수요 임베딩 = **프리페치 질의** (표류 캐시의 학습판 —
  TCM을 손으로 쓰지 않고 배우게 하는 것).
- f의 loss 급등 = **회수 놀람** = 작업 전환 신호(캐시 재구성 트리거).
- 저장 가치는 이 모델의 몫이 아니다 — 저장은 널널하게(forget 철학: 저장
  싸고 침강 가역), **가치는 회수 수요가 사후 판정** (수요 0 → 침강,
  반복 수요 → 컴파일 사다리). "무엇을 남길까"를 예측 문제에서 통계
  문제로 강등한 것이 이 설계의 핵심 수다.

## 5. 설계 결정 (성공 기준 ③)

1. **예측 대상 = 다음 사용(회수) 이벤트의 임베딩.** 재구성이 아님 —
   태스크=목적 일치로 outer loop 불요가 근거. (이벤트 전체 스트림 예측은
   기각: 저장 스트림은 훅 캡처·저널로 오염된 비정상 시퀀스.)
2. **갱신 = online, 사용 이벤트마다 1 gradient step** + momentum(S_t 형태
   차용) + 고정 weight decay + 놀람 지속 급증 시 리셋. 이벤트 주파수가
   낮아(일 수백) 병렬화·chunk 불요 — Titans 기계장치의 대부분이 우리
   체제에선 불필요, **핵심 차용은 수식이 아니라 "hidden state = 작은 모델,
   갱신 = 학습"이라는 프레임과 momentum·decay의 형태**다.
3. **평가 = 오프라인 리플레이 recall@k, 기준선 사다리** — 유사도-only(현행
   훅) → +시간 이웃(contiguity, EM-LLM 직역 — 학습 0 부품) → +사용 통계 →
   f(학습). 어느 칸에서 점프가 나는지가 "지능이 필요한 자리"의 실측.
   f의 loss를 게이트로 쓰는 실험은 별도 등록(리플레이 통과 후).

**공짜 부품 (training-free, 즉시 유효)**: EM-LLM의 contiguity buffer —
회수 시 시간 이웃 동반. 현행 훅에 없는 검증된 기전이고 forget의
_expand_temporal_neighbors 기관이 이미 절반을 갖고 있다 — 사다리 2칸이
사실상 배선만 남음.

## 10. P-M-3 등록 (2026-08-29, 숫자 보기 전 고정) — 잔여 2건

**팔 A — f 랭커화 재도전** (P-M-1 사인=출력 채널의 수리):
- 재설계: f는 질의 생성기가 아니라 **ID 후보 풀 위의 랭커** —
  score(m) = h_tᵀ W e_m + β·actr(m), W₀=0, β=1 → **출발선이 actr과 동일**
  (채널 불리 제거 — P-M-1 f 교훈의 집행). W는 online 갱신: t+1의 실제
  selected=양성, 후보 중 미선택=음성, logistic SGD (채점 후 갱신 — 누수 0).
- 판정: 후반 30% recall@10이 actr(0.6605) 대비 **+5pp 이상 → 학습 채택** /
  +2pp 미만 → 학습 재도전 종결(현 데이터 체제에선 통계로 충분 확정).
**팔 B — contiguity 이웃 재정의**:

## 12. P-M-4 등록 (2026-08-29, 숫자 보기 전 고정) — 공정한 학습 랭커

- **훈련**: 각 task 전반 70%(warm)에서 표본 수집 → 다중 에폭 + BPR 랭킹
  손실(양성=t+1 selected, 음성=후보 중 비선택 샘플) + warm 후반 10%로
  조기 종료. 후보 풀 = actr 풀 (기준선과 동일 — 공정).
- **평가 (자 불변)**: 각 task 후반 30% recall@10 vs actr 0.6605.

  −2pp 미만 → 이번에는 진짜 종결(컨텍스트 포함 표준 랭커로도 통계에
