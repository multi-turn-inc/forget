# 개인 세계모델 — 탑다운 설계 헌장 (2026-08-24)

정훈 지시: "생각을 타당하게 구체화. 탑다운으로 들어가자."
선행: docs/world-models-survey.md (지형·§7 구조), L2 4팔 판정 (eab20c9).

## 0. 탑다운이 타당하려면 — 네 가지 규율

1. **필연 도출**: 각 층은 윗층이 강제해야 한다 ("~하면 좋다"가 아니라
   "~없이는 윗층이 성립 불가"). 선호로 고른 가지는 표시해 둔다.
2. **대안 처형**: 갈림마다 경쟁 가설을 이름 붙여 죽이고 사인(死因)을 기록한다.
   대안 없는 도출은 합리화다.
3. **잎은 반증 가능**: 모든 말단 주장에 계기와 등록선을 단다.
4. **나무는 정본으로**: 이 문서가 판정에 따라 갱신되는 살아있는 지도다.
   (지도가 원장을 이긴다 — 로드맵 3규칙 승계)

## L0. 목적 (정의)

**미래의 순간 t에 에이전트가 옳게 행동하는 데 필요한 과거를, 그 순간에,
비용 안에서 공급한다.**

형식화: max E[U(공급 맥락, 미래 과제 t)] − C(토큰·지연·프라이버시).
회고("무엇을 저장했나")가 아니라 전망("다음에 필요할 것을 앞서 담았는가")이
목적함수다 — 8/24 Badre 대화에서 정훈이 확정: "전망은 기억의 부가기능이
아니라 존재 이유". LME·도그푸드 helped/noise는 이 목적함수의 대리 계기.

## L1. 요구사항 (L0에서 필연 도출 — 각각 실측 병리와 짝)

- **R1 예측**: t가 무엇을 필요로 할지 t 이전에 알아야 한다. 반응적 검색만으로는
  "빠진 것을 모른다". 실측: 무검색 오답 27% (D 팔), 증거 기아 15/26 (해부).
  → 기대 생성기 = 세계모델이 필요해지는 지점.
- **R2 접지**: 공급 내용은 이 사람에 대해 참이어야 한다. 생성은 작화한다.
  실측: 리더 추측 오답 (B84 유형별 잔존 오류), vmPFC 환자 구조 (Badre).
  → 일화 영수증 + 생성-재인 검증.
- **R3 갱신**: 세계는 변한다 — 공급 시점 기준 유효해야 한다. 실측: 더듬기
  knowledge-update 퇴행 (구판 간섭), 필드의 STALE 문제.
  → 상태 유지·supersede·시간 구동 진화.
- **R4 경제**: 예산은 유한하다 (컨텍스트·계산·프라이버시). 실측: 예산-정확도
  곡선 전체, 도그푸드 800 토큰 캡슐.
  → 압축·선별·망각.

## L2. 기능 분해 (R에서 도출) + 정합 제약

- R1 → **예측 기계**: 전이 모델 + 기대 헤드
- R2 → **영수증 기계**: 일화 저장 + 검증 루프
- R3 → **갱신 기계**: 상태 코어 + supersede/억제 + 시간 전이
- R4 → **경제 기계**: 쓰기 게이트 + 조립기 + 망각
정합 제약(분리 원칙, 서베이 §7): A 관측↔상태 · B 구조↔내용 · C 예측↔검증.

### 대안 처형 표 (오늘 밤 실측이 사인)

| 경쟁 가설 | 사인 | 영수증 |
|---|---|---|
| "검색만 키우면 된다" (RAG-only) | 검색 만점인데 졌다 | 바늘@84=1.00, 18pp 격차는 하류 |
| "컨텍스트만 키우면 된다" | 단발 조립 0.60 포화 | P-L2-C′ (예산 무관) |

| "LLM 암묵 모델로 충분" | 구조 없는 예측의 취약성·무개인화 | NYC 택시 계열 + 우리 27% 무검색 오답 |
| "상황별 스위치보드" | (기존 판정 승계) | 8/23 반증, 단일 탁월 조립기 노선 |

## L3. 상태 온톨로지 (구체화의 크럭스 — 여기가 지금 층)

세계모델의 품질 상한은 상태 정의가 정한다. 후보 온톨로지 v0 — 다섯 유형:

1. **엔티티** (사람·프로젝트·장소·도구): 타입, 현황, 별칭. [기질에 부분 존재]
2. **열린 고리** (과제·약속·질문·마감): 생애주기 FSM
   `열림 → 진행 → 낡음(시간 승격) → 종결/만료`. **시간만으로도 전이한다.**
3. **루틴** (반복 구조): 주기·위상·다음 기대 발생. 부재 기대의 원천.
4. **성향** (느린 잠재변수): 취향·원칙·가치. 높은 관성, supersede만으로 갱신.
5. **관계 간선**: 유형 붙은 엔티티 간 관계 + 유효 구간.

각 유형은 세 함수를 정의해야 완전하다: 전이 규칙(무엇이 바꾸나, 시간 포함) ·
관측 매핑(어떤 관측이 갱신하나) · 기대 함수(무엇을 예측하나).

**타당성 검사 = 온톨로지 커버리지 감사 (P-WM-1, 숫자 보기 전 등록):**
실수요 표본(도그푸드 턴리콜 질의 50 + LME 100문항)을 "어느 상태 유형이
답했겠는가"로 분류한다.
- 채택: 5유형이 표본의 ≥90%를 덮고, 각 유형 점유 ≥2%.
- 부분: 커버 80~90% → 미커버 군집에서 6번째 유형 후보 도출.
- 기각: <80% → 온톨로지 재설계 (상향 재도출).
- 어떤 유형 점유 <2% → 그 유형은 v0에서 제거(사변적 지방).

**판정 사슬 (2026-08-24 집행 완료):**
- v0 기각 — 커버 66%. 해부: none 34%의 지배 군집 = 날짜 붙은 사건들의
  세기·정렬·집계 (LME temporal 20/27·multi 13/26). 구조적 실수 = 현재(상태)만
  모델링하고 과거-구조(시간축 사건)를 빠뜨림. disposition 1.3%·relation 0.7%
  → <2% 규칙으로 제거 (relation은 entity 속성으로 흡수, disposition은
  기억층 잔류 — 조언형 질의 ~4건이 여기 살았음을 공시).
- 재설계: **event**(시간축 사건 — 쿼드러플+유효구간+부분순서, 선행: 시간 KG·
  EventKG·lifespan events) 추가 → 4유형.
- P-WM-1b(v1.1) **채택** — 진성 수요 111건 커버리지 100% (none 0), 점유:
  event 55.9% · entity 28.8% · open_loop 11.7% · routine 3.6% (전원 ≥2%).
  강건성: 분류 오류 2건(나이 산술→event)을 어느 쪽으로 재배정해도 100% 유지.
- 계기 수리 2건 공시: ①요약 인쇄기가 none을 커버로 오계상(100% 오인쇄)
  ②none이 "수요-미커버"와 "수요 아님"을 혼재 → not_a_demand 분리, 분모는
  진성 수요만. 도그푸드 원천 소음 32/50 — 턴리콜 훅에 수요 필터 필요(후속).
- **확정 상태 유형 4종: entity · event · open_loop · routine.**
  구축 서열 = 수요 점유순: 사건 → 엔티티 → (고리 v0 가동 중) → 루틴.
  용어 규약: 대외 표면에서는 '온톨로지' 대신 **'상태 유형'**(정훈 지시).

## L4. 계산 사다리 (기능별 최소 기제 → 상향 경로)

- 전이: v0 규칙 FSM(고리 생애주기·시간 전이) → v1 계수/SR 통계(루틴) →
  v2 빌린 LLM 시뮬레이션(긴 꼬리) → v3 가중치(QLoRA, W-트랙).
- 기대 헤드: v0 질문유형→증거모양 틀 → v1 상태 제약 LLM 시뮬레이션(본선 6).
- 검증: 현행(억제 간선·생성-재인) + 예측 오차의 검증 우선순위화.
- 게이트: 현행 3요소 → 예측 오차 need 승격 ("내 예측과 다른가").
원칙: 층마다 가장 싼 기제부터, 등록 A/B로만 승급. (D2a/b 절제가 첫 계단)

## L5. 계기망

- L0 대리: LME L1/L2 (외부 gold) + 도그푸드 helped/noise (플라이휠)
- L1: 요구별 실측 병리 추적 (위 표의 영수증 갱신)
- L3: P-WM-1 커버리지 감사
- L4: 계단별 등록 A/B (P-L2-D2a/b 진행 중 → 이후 P-WM-2…)
- 메타: 숫자 전 등록 · 지도가 원장을 이긴다 · 자를 먼저 의심할 것

## 실행 서열 (탑다운이 스스로 답한 다음 손)

1. **P-WM-1 온톨로지 커버리지 감사** — 아무것도 짓기 전에 상태 정의부터 검증
   (탑다운의 요체: 장기 이식 전에 해부도 검증). 비용 $0, 반나절.
2. D2a/b 절제 판정 (0층 하한, 예정대로) → L4 사다리 첫 승급 판정.
3. 감사 통과 유형부터 세 함수(전이·관측·기대) v0 구현 — 유력 선두:
   열린 고리 FSM의 시간 전이 (서베이 §7 빈칸 ①과 일치).
